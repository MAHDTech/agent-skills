Roadmap

# What we're building

Delta is in public beta. This roadmap covers what we’re currently working on and what's up next. Scope and sequencing may change as the work develops.

### What we're working on now(6 features)

*   #### Repository-based access
    
    In Progress
    
    Use your GitHub repository’s existing permissions to control access to shared Delta threads.
    
*   #### Remote runtime
    
    In Progress
    
    Run agents in persistent cloud development environments, with their activity and changes synchronized back to the thread.
    
*   #### Delta CLI
    
    In Progress
    
    Connect any agent to Delta threads and worktrees from the command line, and hand off work across people and machines.
    
*   #### MCP support
    
    In Progress
    
    Connect agents to external tools and data sources through the Model Context Protocol (MCP).
    
*   #### @mentions
    
    In Progress
    
    Tag a teammate in a thread to bring them into the conversation or ask for a review.
    
*   #### ACP support
    
    In Progress
    
    Bring external agents like Claude Code into Delta through the Agent Client Protocol (ACP).
    

### What we're working on next(6 features)

*   #### Repository-level context
    
    Up Next
    
    Access comments and conversations across every worktree in a repository, so the context behind the code is there when you need it.
    
*   #### Sandboxing
    
    Up Next
    
    Run agents in isolated environments, with control over what each agent can access.
    
*   #### WSL support
    
    Up Next
    
    Use Delta on Windows through Windows Subsystem for Linux.
    
*   #### Conversation branching
    
    Up Next
    
    Fork a conversation to explore a different approach without losing the original thread.
    
*   #### Graph view
    
    Up Next
    
    Understand how your repository evolved, from conversations and agent work to branches and commits.
    
*   #### Read and View permissions
    
    Up Next
    
    Control access levels when you share a thread, so teammates can follow the conversation and code without making changes.
