# devenv

> Fast, Declarative, Reproducible, and Composable Developer Environments using Nix

devenv is a fast, declarative, reproducible, and composable development environment tool using Nix.
It allows developers to define project-specific development environments with support for 50+ programming languages,
100+ services, processes, containers, and automated testing.
