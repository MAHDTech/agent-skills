## Files

### devenv.nix

The only required file for specifying the developer environment.

Generated by `devenv init` and thoroughly documented, starting with [the basics](https://devenv.sh/basics/index.md).

### devenv.local.nix

Same as `devenv.nix`, but not meant to be committed into the Git repository so that developers can override some things for their local use case.

### devenv.local.yaml

Added in `1.10`

Same as `devenv.yaml`, but not meant to be committed into the Git repository so that developers can override some things for their local use case.

### devenv.yaml

Configuration for [inputs](https://devenv.sh/inputs/index.md) and [imports](https://devenv.sh/composing-using-imports/index.md), allowing you to specify dependencies and how to compose them.

You can require a specific devenv version to make sure all developers use a compatible version:

devenv.yaml

```
# Enforce CLI matches the modules version
require_version: true

# Or use an explicit constraint
require_version: ">=2.1"
```

See [devenv.yaml reference](https://devenv.sh/reference/yaml-options/#require_version) for details.

### devenv.lock

Pinned [inputs](https://devenv.sh/inputs/index.md), making sure your developer environment is reproducible.

### .envrc

[direnv](https://direnv.net) integration logic.

See [direnv integration](https://devenv.sh/integrations/direnv/index.md) to set up your shell to automatically activate the developer environment when you `cd` into it.
