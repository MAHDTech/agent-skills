# Bun API Reference

This is the complete API reference for Bun, documenting all available
APIs, types, and functions. Use the sidebar navigation to browse modules
and specific APIs, which are color-coded by type.

This documentation is generated from Bun's TypeScript definitions, which
you can find in the [oven-sh/bun
repository](https://github.com/oven-sh/bun/tree/main/packages/bun-types)
under `packages/bun-types`.
