## gh pr

Work with GitHub pull requests.

### General commands

- [gh pr create](https://cli.github.com/manual/gh_pr_create)
- [gh pr list](https://cli.github.com/manual/gh_pr_list)
- [gh pr status](https://cli.github.com/manual/gh_pr_status)

### Targeted commands

- [gh pr checkout](https://cli.github.com/manual/gh_pr_checkout)
- [gh pr checks](https://cli.github.com/manual/gh_pr_checks)
- [gh pr close](https://cli.github.com/manual/gh_pr_close)
- [gh pr comment](https://cli.github.com/manual/gh_pr_comment)
- [gh pr diff](https://cli.github.com/manual/gh_pr_diff)
- [gh pr edit](https://cli.github.com/manual/gh_pr_edit)
- [gh pr lock](https://cli.github.com/manual/gh_pr_lock)
- [gh pr merge](https://cli.github.com/manual/gh_pr_merge)
- [gh pr ready](https://cli.github.com/manual/gh_pr_ready)
- [gh pr reopen](https://cli.github.com/manual/gh_pr_reopen)
- [gh pr revert](https://cli.github.com/manual/gh_pr_revert)
- [gh pr review](https://cli.github.com/manual/gh_pr_review)
- [gh pr unlock](https://cli.github.com/manual/gh_pr_unlock)
- [gh pr update-branch](https://cli.github.com/manual/gh_pr_update-branch)
- [gh pr view](https://cli.github.com/manual/gh_pr_view)

### Options

`-R`, `--repo <[HOST/]OWNER/REPO>`  
Select another repository using the \[HOST/\]OWNER/REPO format

### Examples

``` bash
$ gh pr checkout 353
$ gh pr create --fill
$ gh pr view --web
```
