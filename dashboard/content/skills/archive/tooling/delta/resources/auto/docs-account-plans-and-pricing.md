# Plans & Usage

How your Zed plan controls model access and usage in Delta.

On this page

1.  [Model access](#model-access)
2.  [Usage and spend limits](#usage-and-spend-limits)

Delta is built by [Zed](https://zed.dev) and uses the same plans and billing as the Zed editor. If you already have a Zed subscription, it covers Delta. See [Delta’s pricing page](/pricing) for current prices, credits, usage rates, and trial terms.

## [Model access](#model-access)

You can connect models in three ways:

*   **Your own API keys.** Every plan can connect supported providers with your own API keys. See [Models & Providers](/docs/agents/models-and-providers).
*   **An existing provider subscription.** Connect a supported ChatGPT, GitHub Copilot, or Grok subscription. Usage follows that provider’s limits rather than drawing from your Zed credits.
*   **Hosted models.** Hosted model access requires a Zed plan or seat that includes hosted AI. Usage draws from the same credits and spend limits as hosted AI in Zed.

If you belong to more than one Zed organization, onboarding lets you choose which organization provides hosted models. That organization’s hosted-model access and spending limits apply. A Zed Business organization can disable hosted models in its configuration.

## [Usage and spend limits](#usage-and-spend-limits)

Hosted model usage is metered on a token basis. Monthly included credit resets on your billing date; you can view usage and set a monthly spend limit from the Billing page at [dashboard.zed.dev](https://dashboard.zed.dev). Once a spend limit is hit, hosted model usage pauses until the limit resets or is raised.

For complete plan details, hosted model rates, and billing terms, see the [Zed documentation](https://zed.dev/docs/account/plans-and-pricing).
