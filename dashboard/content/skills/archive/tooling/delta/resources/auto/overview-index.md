# Delta brings meaning back to your code

Your conversations and code live in one place. Delta anchors every change, so your reasoning lives on with the results.

[Download](/download)[Open Delta](/threads)[Learn more about Delta in the docs](/docs)

## Two ways in, one foundation

Work in the Delta app or from your terminal. DeltaDB keeps both in the same thread.

First-party harness

### Delta, the app

Threads with your team and your agents, side by side.

*   Desktop
*   Web
*   Mobile

[Download the app](/download)

The agent you already use

### Delta CLI Coming soon

Share a session, and a teammate joins from their own.

### DeltaDB, underneath both

The version control system that records every edit with the conversation behind it. A thread shared from Claude Code can be joined from the Delta app, and the other way around.

[Learn about DeltaDB](/deltadb)

Swap the model, the harness, or the machine. Every change, and the conversation behind it, stays in DeltaDB.

## Coding with agents is multiplayer

Invite teammates into the same thread to review, comment, and work alongside the agent in real time.

## See how the code came to be

The thread stays connected to every change, so you understand the decisions and prompts behind the code.

## Review in context

Comment on the conversation or any line of code. Your feedback stays anchored as the work evolves.

## Take your thread anywhere

Open Delta from the desktop or web, or move to a cloud runner. The conversation and code stay synchronized.
