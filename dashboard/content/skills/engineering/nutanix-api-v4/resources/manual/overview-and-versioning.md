# Nutanix v4 API Overview and Versioning

### Nutanix v4 API Release Notes

Nutanix v4 API Hosted March 24, 2026

### Contents

## INTRODUCTION

Nutanix v4 APIs were made generally available (GA) with AOS 7.0 and Prism Central pc.2024.3. Nutanix v4 APIs integrate modern standards and scalability while simplifying the overall developer experience. Theyoffer a comprehensive and consistent set of APIs and SDKs for operating the Nutanix Cloud Platform . These v4APIs have semantics based on open API standards and deliver an intuitive and efficient user experience. The new v4 API family delivers a host of new features for Nutanix API users that includes the following:

| • | Language-specific SDKs that support Python, Go, Java, and JavaScript |
| --- | --- |
| • | A new developer portal with a comprehensive set of API, SDK documentation, and code samples |
| • | API versioning support |
| • | Improved usability, filtering, sorting, and selection through OData |

Note: Nutanix Legacy API versions v0.8, v1, v2, and v3 will be deprecated and no longer supported starting withthe AOS and PC upgrade release planned for Q4-CY2026. Customers with active service contracts will continue toreceive support from Nutanix as per the Nutanix EOSL policy. Nutanix strongly recommends that all our customers andpartners migrate their applications and tools to the latest v4 APIs and SDKs before the legacy APIs are deprecated.
