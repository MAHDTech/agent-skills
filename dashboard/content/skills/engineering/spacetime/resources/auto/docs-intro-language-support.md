id="server-database-modules">Server Database Modules<a href="#server-database-modules" class="hash-link" aria-label="Direct link to Server Database Modules" title="Direct link to Server Database Modules" translate="no">​</a></h2>
<p>SpacetimeDB modules define your database schema and server-side business logic. Modules can be written in four languages:</p>
\<ul\>
<li class=""><strong><a class="" href="/docs/databases">Rust</a></strong> - High performance, compiled to WebAssembly <a class="" href="/docs/quickstarts/rust">(Quickstart)</a></li>
<li class=""><strong><a class="" href="/docs/databases">C#</a></strong> - Great for Unity developers, compiled to WebAssembly <a class="" href="/docs/quickstarts/c-sharp">(Quickstart)</a></li>
<li class=""><strong><a class="" href="/docs/databases">TypeScript</a></strong> - Ideal for web developers, runs on V8 <a class="" href="/docs/quickstarts/typescript">(Quickstart)</a></li>
<li class=""><strong><a class="" href="/docs/databases">C++</a></strong> - Fits Unreal and C++ workflows, compiled to WebAssembly <a class="" href="/docs/quickstarts/c-plus-plus">(Quickstart)</a></li>
</ul>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="client-sdks">Client SDKs<a href="#client-sdks" class="hash-link" aria-label="Direct link to Client SDKs" title="Direct link to Client SDKs" translate="no">​</a></h2>
<p><strong>Clients</strong> are applications that connect to SpacetimeDB databases. The <code>spacetime</code> CLI tool can automatically generate type-safe client code for your database.</p>
\<ul\>
<li class=""><strong><a class="" href="/docs/clients/rust">Rust</a></strong> - <a class="" href="/docs/quickstarts/rust">(Quickstart)</a></li>
<li class=""><strong><a class="" href="/docs/clients/c-sharp">C#</a></strong> - <a class="" href="/docs/quickstarts/c-sharp">(Quickstart)</a></li>
<li class=""><strong><a class="" href="/docs/clients/typescript">TypeScript</a></strong> - <a class="" href="/docs/quickstarts/typescript">(Quickstart)</a></li>
<li class=""><strong><a class="" href="/docs/clients/unreal">Unreal Engine</a></strong> - C++ and Blueprint support <a class="" href="/docs/tutorials/unreal/part-1">(Tutorial)</a></li>
</ul>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="unity">Unity<a href="#unity" class="hash-link" aria-label="Direct link to Unity" title="Direct link to Unity" translate="no">​</a></h3>
<p>SpacetimeDB was designed first and foremost as the backend for multiplayer Unity games. The C# SDK integrates seamlessly with Unity projects.
