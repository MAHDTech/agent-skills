<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="restrictions">Restrictions<a href="#restrictions" class="hash-link" aria-label="Direct link to Restrictions" title="Direct link to Restrictions" translate="no">​</a></h2>
<p>Default values <strong>cannot</strong> be combined with:</p>
\<ul\>
<li class="">Primary keys</li>
<li class="">Unique constraints</li>
<li class=""><a class="" href="/docs/tables/auto-increment">Auto-increment</a></li>
</ul>
<p>This restriction exists because these attributes require the database to manage the column values, which conflicts with providing a static default.</p>

<span class="line"><span style="color:#F8F8F2">  { name</span><span style="color:#FF79C6">:</span><span style="color:#E9F284"> &#x27;</span><span style="color:#F1FA8C">bad</span><span style="color:#E9F284">&#x27;</span><span style="color:#F8F8F2"> },</span></span>
