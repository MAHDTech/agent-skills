markdown">\<header\>\<h1\><code>/v1/database</code></h1></header>
<p>The HTTP endpoints in <code>/v1/database</code> allow clients to interact with Spacetime databases in a variety of ways, including retrieving information, creating and deleting databases, invoking reducers and evaluating SQL queries. These APIs are intended primarily for management, debugging and interactive developer use, and have not been optimized for performance to the same extent as the WebSocket API used by <a class="" href="/docs/clients">the SpacetimeDB client SDKs</a>.</p>

<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="publishing-with-environment-values">Publishing with environment values<a href="#publishing-with-environment-values" class="hash-link" aria-label="Direct link to Publishing with environment values" title="Direct link to Publishing with environment values" translate="no">​</a></h3>
<p>Both publish endpoints accept <a class="" href="/docs/databases/environment-variables">environment values</a> in headers, alongside the module in the body. Send one <code>spacetime-environment</code> header per value, in the form <code>KEY=VALUE</code>:</p>
<div class="language-text codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><div class="codeBlockContent_VOyQ"><pre tabindex="0" class="prism-code language-text codeBlock_evfK thin-scrollbar" style="color:#bfc7d5;background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="token-line" style="color:#bfc7d5"><span class="token plain">spacetime-environment: API_KEY=development-only-key</span><br></span><span class="token-line" style="color:#bfc7d5"><span class="token plain">spacetime-environment: MODE=development</span><br></span></code></pre></div></div>
<p>Values are written like shell or <code>.env</code> assignments:</p>
\<ul\>
<li class="">A bare value, such as <code>API_KEY=abc123</code>, is taken literally. It cannot contain spaces, tabs, quotes, <code>,</code> or <code>\</code>.</li>
<li class="">A single-quoted value, such as <code>GREETING=&#x27;hello, world&#x27;</code>, is taken literally up to the closing quote. It cannot contain <code>&#x27;</code>.</li>
<li class="">A double-quoted value, such as <code>PEM="line1\nline2"</code>, supports JSON string escapes, as in <code>.env</code> files: <code>\"</code>, <code>\\</code>, <code>\n</code>, <code>\t</code>, and <code>\uXXXX</code> for other control characters and non-ASCII characters, which cannot appear raw in a header.</li>
</ul>
<p>Unlike a shell, the server does not expand variables. Values that break these rules, such as <code>GREETING=hello world</code>, are rejected with <code>400 Bad Request</code>. The server also accepts several values in one header, separated by commas outside quotes.</p>
<p>Formally, in <a href="https://www.rfc-editor.org/rfc/rfc5234" target="_blank" rel="noopener noreferrer" class="">ABNF</a>, using the list syntax (<code>#</code>) from <a href="https://www.rfc-editor.org/rfc/rfc9110#section-5.6.1" target="_blank" rel="noopener noreferrer" class="">RFC 9110</a>:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span>spacetime-environment = #assignment</span></span>
<span class="line"><span>assignment    = key "=" value</span></span>
<span class="line"><span>key           = ( ALPHA / "_" ) *( ALPHA / DIGIT / "_" )</span></span>
<span class="line"><span>value         = bare / single-quoted / double-quoted</span></span>
<span class="line"><span>bare          = *( %x21 / %x23-26 / %x28-2B / %x2D-5B / %x5D-7E )</span></span>
<span class="line"><span>                ; visible ASCII except " &#x27; , \</span></span>
<span class="line"><span>single-quoted = "&#x27;" *( HTAB / %x20-26 / %x28-7E ) "&#x27;"</span></span>
<span class="line"><span>                ; taken literally</span></span>
<span class="line"><span>double-quoted = DQUOTE *( %x20-21 / %x23-5B / %x5D-7E / escape ) DQUOTE</span></span>
<span class="line"><span>escape        = "\" ( DQUOTE / "\" / "/" / %x62 / %x66 / %x6E / %x72 / %x74 / %x75 4HEXDIG )</span></span>
<span class="line"><span>                ; \" \\ \/ \b \f \n \r \t \uXXXX, lowercase only, as in JSON</span></span>
<span class="line"><span>                ; strings (RFC 8259). A \u escape of a UTF-16 high surrogate must be</span></span>
<span class="line"><span>                ; followed by one of a low surrogate, and a low surrogate cannot</span></span>
<span class="line"><span>                ; appear on its own.</span></span>
<span class="line"><span></span></span>
<span class="line"><span>spacetime-environment-remove = #( "*" / key )</span></span>
<span class="line"><span>                ; "*" must be the only element</span></span></code></pre>
<p>Keys are at most 256 bytes and values at most 8 KiB. A key cannot appear twice across all <code>spacetime-environment</code> headers.</p>
<p>Supplied values override stored values with the same key, and stored values that are not supplied are kept. To delete stored values, list their keys in a <code>spacetime-environment-remove</code> header, separated by commas (<code>OLD_KEY, _UNUSED</code>). To replace the whole environment with only the supplied values, send <code>spacetime-environment-remove: *</code>. A key cannot be both supplied and removed.</p>
<p>The server validates the resulting environment against the module&#x27;s declarations and installs the module and the environment in one transaction. All required values must be present, and every declared value must satisfy its declaration. Invalid updates leave the database unchanged.</p>
<p>If a required value is missing, the server returns <code>400 Bad Request</code> with JSON that names the missing key, so clients can prompt for it and retry:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#F8F8F2">{</span></span>
<span class="line"><span style="color:#8BE9FE">  "</span><span style="color:#8BE9FD">EnvironmentError</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span style="color:#F8F8F2"> { </span><span style="color:#8BE9FE">"</span><span style="color:#8BE9FD">MissingRequiredEnvironment</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span style="color:#F8F8F2"> { </span><span style="color:#8BE9FE">"</span><span style="color:#8BE9FD">keys</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span style="color:#F8F8F2"> [</span><span style="color:#E9F284">"</span><span style="color:#F1FA8C">API_KEY</span><span style="color:#E9F284">"</span><span style="color:#F8F8F2">] } }</span></span>
<span class="line"><span style="color:#F8F8F2">}</span></span></code></pre>
<p>A reset (<code>clear=true</code>) deletes all stored values, so the request must supply every required value again.</p>
<p>For example, to publish a module to a local server with <code>curl</code>, export <code>SPACETIME_TOKEN</code> with a token authorized to publish, then run:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">curl</span><span style="color:#BD93F9"> --fail-with-body</span><span style="color:#BD93F9"> --request</span><span style="color:#F1FA8C"> PUT</span><span style="color:#FF79C6"> \</span></span>

<span class="line"><span style="color:#BD93F9">  --header</span><span style="color:#E9F284"> &#x27;</span><span style="color:#F1FA8C">spacetime-environment: API_KEY=development-only-key</span><span style="color:#E9F284">&#x27;</span><span style="color:#FF79C6"> \</span></span>
<span class="line"><span style="color:#BD93F9">  --header</span><span style="color:#E9F284"> &#x27;</span><span style="color:#F1FA8C">spacetime-environment: MODE=development</span><span style="color:#E9F284">&#x27;</span><span style="color:#FF79C6"> \</span></span>
<span class="line"><span style="color:#BD93F9">  --data-binary</span><span style="color:#F1FA8C"> @module.wasm</span></span></code></pre>
<p>To change environment values without publishing a module, use <a href="#put-v1databasename_or_identityenvironment" class=""><code>PUT</code></a> or <a href="#patch-v1databasename_or_identityenvironment" class=""><code>PATCH /v1/database/:name_or_identity/environment</code></a>.</p>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="get-v1databasename_or_identitylogs"><code>GET /v1/database/:name_or_identity/logs</code><a href="#get-v1databasename_or_identitylogs" class="hash-link" aria-label="Direct link to get-v1databasename_or_identitylogs" title="Direct link to get-v1databasename_or_identitylogs" translate="no">​</a></h2>
<p>Retrieve logs from a database.</p>
<p>Accessible through the CLI as <code>spacetime logs \<name_or_identity\></code>.</p>
<h4 class="anchor anchorTargetStickyNavbar_Y_NL" id="query-parameters-5">Query Parameters<a href="#query-parameters-5" class="hash-link" aria-label="Direct link to Query Parameters" title="Direct link to Query Parameters" translate="no">​</a></h4>
<table><thead><tr><th>Name</th><th>Value</th></tr></thead>\<tbody\><tr><td><code>num_lines</code></td><td>Number of most-recent log lines to retrieve.</td></tr><tr><td><code>follow</code></td><td>A boolean; whether to continue receiving new logs via a stream.</td></tr></tbody></table>
<h4 class="anchor anchorTargetStickyNavbar_Y_NL" id="optional-headers-9">Optional Headers<a href="#optional-headers-9" class="hash-link" aria-label="Direct link to Optional Headers" title="Direct link to Optional Headers" translate="no">​</a></h4>
<table><thead><tr><th>Name</th><th>Value</th></tr></thead>\<tbody\><tr><td><code>Authorization</code></td><td>A Spacetime token <a class="" href="/docs/http/authorization#authorization-headers">as Bearer auth</a>.</td></tr></tbody></table>
<p>Viewing logs requires ownership of the database. If no <code>Authorization</code> header is provided, the request will be treated as anonymous and will be rejected.</p>
<h4 class="anchor anchorTargetStickyNavbar_Y_NL" id="returns-11">Returns<a href="#returns-11" class="hash-link" aria-label="Direct link to Returns" title="Direct link to Returns" translate="no">​</a></h4>
<p>Text, or streaming text if <code>follow</code> is supplied, containing log lines.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="post-v1databasename_or_identitysql"><code>POST /v1/database/:name_or_identity/sql</code><a href="#post-v1databasename_or_identitysql" class="hash-link" aria-label="Direct link to post-v1databasename_or_identitysql" title="Direct link to post-v1databasename_or_identitysql" translate="no">​</a></h2>
<p>Run a SQL query against a database.</p>
<p>Accessible through the CLI as <code>spacetime sql \<name_or_identity\> \<query\></code>.</p>
<h4 class="anchor anchorTargetStickyNavbar_Y_NL" id="optional-headers-10">Optional Headers<a href="#optional-headers-10" class="hash-link" aria-label="Direct link to Optional Headers" title="Direct link to Optional Headers" translate="no">​</a></h4>
<table><thead><tr><th>Name</th><th>Value</th></tr></thead>\<tbody\><tr><td><code>Authorization</code></td><td>A Spacetime token <a class="" href="/docs/http/authorization#authorization-headers">as Bearer auth</a>.</td></tr></tbody></table>
<p>If no <code>Authorization</code> header is provided, the request will be treated as anonymous and will only have access to public tables. The caller&#x27;s identity is used to enforce row-level security policies.</p>
<h4 class="anchor anchorTargetStickyNavbar_Y_NL" id="data-7">Data<a href="#data-7" class="hash-link" aria-label="Direct link to Data" title="Direct link to Data" translate="no">​</a></h4>
<p>SQL queries, separated by <code>;</code>.</p>
<h4 class="anchor anchorTargetStickyNavbar_Y_NL" id="returns-12">Returns<a href="#returns-12" class="hash-link" aria-label="Direct link to Returns" title="Direct link to Returns" translate="no">​</a></h4>
<p>Returns a JSON array of statement results, each of which takes the form:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#F8F8F2">{</span></span>
<span class="line"><span style="color:#E9F284">    "</span><span style="color:#F1FA8C">schema</span><span style="color:#E9F284">"</span><span style="color:#F8F8F2">: ProductType,</span></span>
<span class="line"><span style="color:#E9F284">    "</span><span style="color:#F1FA8C">rows</span><span style="color:#E9F284">"</span><span style="color:#F8F8F2">: array</span></span>
<span class="line"><span style="color:#F8F8F2">}</span></span></code></pre>
<p>The <code>schema</code> will be a <a class="" href="/docs/sats-json">JSON-encoded <code>ProductType</code></a> describing the type of the returned rows.</p>
<p>The <code>rows</code> will be an array of <a class="" href="/docs/sats-json">JSON-encoded <code>ProductValue</code>s</a>, each of which conforms to the <code>schema</code>.</p>
