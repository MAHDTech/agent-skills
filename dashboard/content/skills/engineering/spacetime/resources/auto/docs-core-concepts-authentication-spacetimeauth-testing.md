<p>Before integrating SpacetimeAuth into your application code, it’s a good idea
to verify that your client and redirect URIs are working correctly. One of the
easiest ways to do this is with <a href="https://oidcdebugger.com" target="_blank" rel="noopener noreferrer" class="">OIDC Debugger</a>.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="why-use-oidc-debugger">Why Use OIDC Debugger?<a href="#why-use-oidc-debugger" class="hash-link" aria-label="Direct link to Why Use OIDC Debugger?" title="Direct link to Why Use OIDC Debugger?" translate="no">​</a></h2>
<p>OIDC Debugger simulates the OAuth2 / OIDC Authorization Code flow in your browser.
It allows you to:</p>
\<ul\>
<li class="">Confirm that your <strong>redirect URIs</strong> are configured properly.</li>
<li class="">Verify that your <strong>client ID</strong> works.</li>
<li class="">Inspect the <strong>ID Token</strong> and claims (<code>email</code>, <code>sub</code>, <code>preferred_username</code>, etc.).</li>
<li class="">Catch configuration issues before writing code.</li>
</ul>
\<hr\>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-1-gather-your-configuration">Step 1: Gather Your Configuration<a href="#step-1-gather-your-configuration" class="hash-link" aria-label="Direct link to Step 1: Gather Your Configuration" title="Direct link to Step 1: Gather Your Configuration" translate="no">​</a></h2>
\<ul\>
<li class="">
<p><strong>Authorization Endpoint</strong>:<br>
<code>https://auth.spacetimedb.com/oidc/auth</code></p>
</li>
<li class="">
<p><strong>Token Endpoint</strong>:<br>
<code>https://auth.spacetimedb.com/oidc/token</code></p>
</li>
<li class="">
<p><strong>Client ID</strong>: From your SpacetimeAuth dashboard, you can use any available client.</p>
</li>
<li class="">
<p><strong>Redirect URI</strong>: <a href="https://oidcdebugger.com/debug" target="_blank" rel="noopener noreferrer" class="">https://oidcdebugger.com/debug</a> must be added to your
client’s allowed redirect URIs in the SpacetimeAuth dashboard.</p>
</li>
</ul>
\<hr\>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-2-open-oidc-debugger">Step 2: Open OIDC Debugger<a href="#step-2-open-oidc-debugger" class="hash-link" aria-label="Direct link to Step 2: Open OIDC Debugger" title="Direct link to Step 2: Open OIDC Debugger" translate="no">​</a></h2>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-3-run-the-flow">Step 3: Run the Flow<a href="#step-3-run-the-flow" class="hash-link" aria-label="Direct link to Step 3: Run the Flow" title="Direct link to Step 3: Run the Flow" translate="no">​</a></h2>
\<ol\>
<li class="">Click <strong>Send Request</strong>.</li>
<li class="">Log in via SpacetimeAuth using any configured providers.</li>
<li class="">You’ll be redirected back to OIDC Debugger with an authorization code.</li>
<li class="">OIDC Debugger will automatically exchange the code for tokens and display the
results.
