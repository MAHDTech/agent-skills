<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="project-setup">Project setup<a href="#project-setup" class="hash-link" aria-label="Direct link to Project setup" title="Direct link to Project setup" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="using-the-unreal-engine-plugin">Using the Unreal Engine Plugin<a href="#using-the-unreal-engine-plugin" class="hash-link" aria-label="Direct link to Using the Unreal Engine Plugin" title="Direct link to Using the Unreal Engine Plugin" translate="no">​</a></h3>
<p>Add the SpacetimeDB Unreal SDK to your project as a plugin. The SDK provides both C++ and Blueprint APIs for connecting to SpacetimeDB modules.</p>

You must either call <code>FrameTick()</code> regularly, typically from an Actor&#x27;s <code>Tick()</code>, or enable automatic ticking once with <code>SetAutoTicking(true)</code>. <h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="observe-and-invoke-reducers">Observe and invoke reducers<a href="#observe-and-invoke-reducers" class="hash-link" aria-label="Direct link to Observe and invoke reducers" title="Direct link to Observe and invoke reducers" translate="no">​</a></h2>
<p>All context types provide access to reducers through the <code>.Reducers</code> property, which contains generated methods for invoking reducers defined by the module and generated delegates for reducer results.</p>
<p>Each reducer defined by the module has methods on the <code>.Reducers</code>:</p>
\<ul\>
<li class="">An invoke method, whose name matches the reducer&#x27;s name (e.g., <code>SendMessage</code>, <code>SetName</code>). This requests that the module run the reducer.</li>
<li class="">A generated delegate, whose name is prefixed with <code>On</code> (e.g., <code>OnSendMessage</code>, <code>OnSetName</code>). This runs when the result for a reducer call made by this connection is received and correlated by <code>request_id</code>.</li>
</ul>

<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="notes-and-limitations">Notes and limitations<a href="#notes-and-limitations" class="hash-link" aria-label="Direct link to Notes and limitations" title="Direct link to Notes and limitations" translate="no">​</a></h3>
\<ul\>
<li class=""><code>OnApplied</code> is the right place to inspect the initial subscribed result set in the client cache.</li>
<li class=""><code>OnInsert</code>, <code>OnUpdate</code>, and <code>OnDelete</code> are for subsequent live changes after the subscription is active.</li>
<li class=""><code>TimeDuration</code> query predicates are currently unsupported.</li>
<li class="">Raw SQL subscriptions remain available when you need manual SQL control.</li>
</ul>
