<p><strong>App Patterns</strong></p>
\<ul\>
<li class=""><a class="" href="/docs/how-to/app-patterns/pagination">Pagination</a> - Load a large feed one page at a time with a view that takes the page number and page size</li>
<li class=""><a class="" href="/docs/how-to/app-patterns/admin-roles">Admin and Moderator Roles</a> - Let moderators and admins do what regular users can&#x27;t, checked in each reducer</li>
<li class=""><a class="" href="/docs/how-to/app-patterns/send-email">Send an Email</a> - Queue emails from reducers and send them from a scheduled procedure, with retries</li>
<li class=""><a class="" href="/docs/how-to/app-patterns/call-external-api">Call an External API</a> - Fetch data from a web API on a schedule and store it in a table that clients subscribe to</li>
<li class=""><a class="" href="/docs/how-to/app-patterns/call-ai-model">Call an AI Model</a> - Generate text from a procedure without exposing your API key</li>
<li class=""><a class="" href="/docs/how-to/app-patterns/call-ai-model-sidecar">Call an AI Model from a Sidecar</a> - Answer players with a separate program next to your database</li>
<li class=""><a class="" href="/docs/how-to/app-patterns/seed-initial-data">Seed Initial Data</a> - Fill tables when the database is created, and update them later with an owner-only reducer</li>
<li class=""><a class="" href="/docs/how-to/app-patterns/store-files-in-s3">Store Files in S3</a> - Let players upload and download files directly to a private bucket, with URLs your module signs</li>
</ul>
</li>
<li class="">
<p><strong>Social Features</strong></p>
\<ul\>
<li class=""><a class="" href="/docs/how-to/social/unique-usernames">Unique Usernames</a> - Keep names unique and reject offensive ones with a word list and a moderation API</li>
<li class=""><a class="" href="/docs/how-to/social/friends-list">Friends or Follow List</a> - Let players follow each other and see their own lists live</li>
<li class=""><a class="" href="/docs/how-to/social/chat-rooms-and-dms">Chat Rooms and Private DMs</a> - Let players chat in rooms and send direct messages that only the right players receive</li>
<li class=""><a class="" href="/docs/how-to/social/typing-indicators">Typing Indicators</a> - Show who&#x27;s typing with an event table, without storing anything</li>
<li class=""><a class="" href="/docs/how-to/social/unread-counts">Unread Counts</a> - Show how many messages each room has that the player hasn&#x27;t read, and notify them about new ones</li>
</ul>
</li>
<li class="">
<p><strong>Multiplayer Games</strong></p>
\<ul\>
<li class=""><a class="" href="/docs/how-to/games/top-100-leaderboard">Top 100 Leaderboard</a> - Keep a live top 100 that clients subscribe to</li>
<li class=""><a class="" href="/docs/how-to/games/fixed-rate-game-tick">Fixed-Rate Game Tick</a> - Run game logic on a schedule</li>
<li class=""><a class="" href="/docs/how-to/games/matchmaking-queue">Matchmaking Queue</a> - Pair waiting players into matches</li>
<li class=""><a class="" href="/docs/how-to/games/skill-based-matchmaking">Skill-Based Matchmaking</a> - Match players of similar skill with OpenSkill</li>
<li class=""><a class="" href="/docs/how-to/games/turn-based-game">Turn-Based Game</a> - Enforce turns and time limits on the server</li>
<li class=""><a class="" href="/docs/how-to/games/sync-nearby-entities">Sync Nearby Players</a> - Send each client only what&#x27;s near its player</li>
<li class=""><a class="" href="/docs/how-to/games/hide-information">Hide Information</a> - Keep tables private and show each player only what they may see</li>
<li class=""><a class="" href="/docs/how-to/games/seasonal-leaderboard-reset">Seasonal Leaderboard</a> - Start the leaderboard over each season and keep a hall of fame</li>
</ul>
</li>
