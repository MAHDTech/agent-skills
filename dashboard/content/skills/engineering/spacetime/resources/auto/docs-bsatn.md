markdown">\<header\>\<h1\>BSATN Data Format</h1></header><p>The Spacetime Algebraic Type Notation binary (BSATN) format defines
how Spacetime <code>AlgebraicValue</code>s and friends are encoded as byte strings.</p>
<p>Algebraic values and product values are BSATN-encoded for e.g.,
module-host communication and for storing row data in the database.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="notes-on-notation">Notes on notation<a href="#notes-on-notation" class="hash-link" aria-label="Direct link to Notes on notation" title="Direct link to Notes on notation" translate="no">​</a></h2>
<p>In this reference, we give a formal definition of the format.
To do this, we use inductive definitions, and define the following notation:</p>
\<ul\>
<li class=""><code>bsatn(x)</code> denotes a function converting some value <code>x</code> to a list of bytes.</li>
<li class=""><code>a: B</code> means that <code>a</code> is of type <code>B</code>.</li>
<li class=""><code>Foo(x)</code> denotes extracting <code>x</code> out of some variant or type <code>Foo</code>.</li>
<li class=""><code>a ++ b</code> denotes concatenating two byte lists <code>a</code> and <code>b</code>.</li>
<li class=""><code>bsatn(A) = bsatn(B) | ... | bsatn(Z)</code> where <code>B</code> to <code>Z</code> are variants of <code>A</code>
means that <code>bsatn(A)</code> is defined as e.g.,
<code>bsatn(B)</code>, <code>bsatn(C)</code>, .., <code>bsatn(Z)</code> depending on what variant of <code>A</code> it was.</li>
<li class=""><code>[]</code> denotes the empty list of bytes.</li>
</ul>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="values">Values<a href="#values" class="hash-link" aria-label="Direct link to Values" title="Direct link to Values" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="at-a-glance">At a glance<a href="#at-a-glance" class="hash-link" aria-label="Direct link to At a glance" title="Direct link to At a glance" translate="no">​</a></h3>
<table><thead><tr><th>Type</th><th>Description</th></tr></thead>\<tbody\><tr><td><a href="#algebraicvalue" class=""><code>AlgebraicValue</code></a></td><td>A value of any type.</td></tr><tr><td><a href="#sumvalue" class=""><code>SumValue</code></a></td><td>A value of a sum type, i.e. an enum or tagged union.</td></tr><tr><td><a href="#productvalue" class=""><code>ProductValue</code></a></td><td>A value of a product type, i.e. a struct or tuple.</td></tr></tbody></table>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="algebraicvalue"><code>AlgebraicValue</code><a href="#algebraicvalue" class="hash-link" aria-label="Direct link to algebraicvalue" title="Direct link to algebraicvalue" translate="no">​</a></h3>
<p>The BSATN encoding of an <code>AlgebraicValue</code> defers to the encoding of each variant:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#F8F8F2">bsatn</span><span style="color:#FF79C6">(</span><span style="color:#F8F8F2">AlgebraicValue</span><span style="color:#FF79C6">)</span></span>
<span class="line"><span style="color:#FF79C6">    =</span><span style="color:#F8F8F2"> bsatn</span><span style="color:#FF79C6">(</span><span style="color:#F8F8F2">SumValue</span><span style="color:#FF79C6">)</span></span>
<span class="line"><span style="color:#FF79C6">    |</span><span style="color:#F8F8F2"> bsatn</span><span style="color:#FF79C6">(</span><span style="color:#F8F8F2">ProductValue</span><span style="color:#FF79C6">)</span></span>
<span class="line"><span style="color:#FF79C6">    |</span><span style="color:#F8F8F2"> bsatn</span><span style="color:#FF79C6">(</span><span style="color:#F8F8F2">ArrayValue</span><span style="color:#FF79C6">)</span></span>

<p>Algebraic values include sums, products, arrays, strings, and primitives types.
The primitive types include booleans, unsigned and signed integers up to 256-bits, and floats, both single and double precision.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="sumvalue"><code>SumValue</code><a href="#sumvalue" class="hash-link" aria-label="Direct link to sumvalue" title="Direct link to sumvalue" translate="no">​</a></h3>
<p>An instance of a sum type, i.e. an enum or tagged union.
<code>SumValue</code>s are binary-encoded as <code>bsatn(tag) ++ bsatn(variant_data)</code>
where <code>tag: u8</code> is an index into the <code>SumType.variants</code>
array of the value&#x27;s <code>SumType</code>,
and where <code>variant_data</code> is the data of the variant.
For variants holding no data, i.e., of some zero sized type,
<code>bsatn(variant_data) = []</code>.</p>
