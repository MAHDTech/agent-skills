class="theme-doc-markdown markdown">\<header\>\<h1\>Unreal Tutorial</h1></header><p>Need help with the tutorial or CLI commands? <a href="https://discord.gg/spacetimedb" target="_blank" rel="noopener noreferrer" class="">Join our Discord server</a>!</p>
<p>In this tutorial you&#x27;ll learn how to build a small-scoped massive multiplayer online action game in Unreal, from scratch, using SpacetimeDB. Although, the game we&#x27;re going to build is small in scope, it&#x27;ll scale to hundreds of players and will help you get acquainted with all the features and best practices of SpacetimeDB, while building <a href="https://github.com/clockworklabs/SpacetimeDB/tree/master/demo/Blackholio" target="_blank" rel="noopener noreferrer" class="">a fun little game</a>.</p>
<p>By the end, you should have a basic understanding of what SpacetimeDB offers for developers making multiplayer games.</p>
<p>The game is inspired by <a href="https://agar.io" target="_blank" rel="noopener noreferrer" class="">agar.io</a>, but SpacetimeDB themed with some fun twists. If you&#x27;re not familiar <a href="https://agar.io" target="_blank" rel="noopener noreferrer" class="">agar.io</a>, it&#x27;s a web game in which you and hundreds of other players compete to cultivate mass to become the largest cell in the Petri dish.</p>
<p>Our game, called <a href="https://github.com/clockworklabs/SpacetimeDB/tree/master/demo/Blackholio" target="_blank" rel="noopener noreferrer" class="">Blackhol.io</a>, will be similar but space themed. It should give you a great idea of the types of games you can develop easily with SpacetimeDB.</p>
<p>This tutorial assumes that you have a basic understanding of the Unreal Engine, using a command line terminal and programming in C++. We&#x27;ll give you some CLI commands to execute. If you are using Windows, we recommend using Git Bash or PowerShell. For Mac, we recommend Terminal.</p>
<p>We’ll keep things intentionally simple: a single “Game Manager” class, minimal error handling, and hardcoded settings where convenient. This makes the SDK flow easy to see. For production, prefer Unreal’s Subsystems, move secrets out of code, follow best practices, and add proper logging/retry.</p>
<p>SpacetimeDB supports Unreal Engine version <code>5.6</code>. This tutorial has been tested only with that version.</p>
<p>This tutorial is written for C++, but the SpacetimeDB Unreal client SDK also supports Blueprints! Stay tuned for a Blueprint-based tutorial.</p>
