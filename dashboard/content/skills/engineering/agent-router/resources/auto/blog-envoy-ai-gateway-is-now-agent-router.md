<p>On 10 September, <strong>Agent Router</strong>, previously <strong>Envoy AI Gateway</strong>, officially joins the
<strong>Agentic AI Foundation</strong>.</p>
<p>Same code. Same maintainers. New home.</p>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="a-new-home">A new home<a href="#a-new-home" class="hash-link" aria-label="Direct link to A new home" title="Direct link to A new home" translate="no">​</a></h2>
<p>Envoy AI Gateway started as an Envoy sub-project within the CNCF. On 10 September it becomes a
standalone project and moves into the Agentic AI Foundation.</p>
<p>This is great news for the community. The AAIF is home to the agentic stack ecosystem, and being
part of it puts Agent Router closer to the projects and people building that stack. We get to
collaborate more directly, and keep building the solutions that power agents together with everyone
else in the foundation.</p>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="what-does-not-change">What does not change<a href="#what-does-not-change" class="hash-link" aria-label="Direct link to What does not change" title="Direct link to What does not change" translate="no">​</a></h2>
<p>Nothing you deploy is renamed. The product name changes in prose only.</p>
\<ul\>
<li class=""><strong>CRDs and API group stay as they are.</strong> <code>AIGatewayRoute</code>, <code>AIServiceBackend</code>,
<code>BackendSecurityPolicy</code>, and the <code>aigateway.envoyproxy.io</code> API group are not being renamed.</li>
<li class=""><strong>The CLI is still <code>aigw</code></strong>, and the <code>envoy-ai-gateway-system</code> namespace stays the same.</li>
<li class=""><strong>Same maintainers, same release cadence, same Apache 2.0 license.</strong></li>
<li class=""><strong>Envoy stays underneath.</strong> Agent Router is still built on Envoy and Envoy Gateway.</li>
</ul>
<p>Your manifests from yesterday apply tomorrow. There is nothing to migrate.</p>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="what-does-change">What does change<a href="#what-does-change" class="hash-link" aria-label="Direct link to What does change" title="Direct link to What does change" translate="no">​</a></h2>
\<ul\>
<li class=""><strong>The name.</strong> Envoy AI Gateway becomes Agent Router.</li>
<li class=""><strong>The repository</strong> moves to
<a href="https://github.com/theagentrouter/agent-router" target="_blank" rel="noopener noreferrer" class=""><code>theagentrouter/agent-router</code></a>. Old
<code>envoyproxy/ai-gateway</code> links redirect.</li>
<li class=""><strong>The website</strong> moves to <a href="https://theagentrouter.ai" target="_blank" rel="noopener noreferrer" class="">theagentrouter.ai</a>. Every
<code>aigateway.envoyproxy.io</code> link redirects to the same page.</li>
<li class=""><strong>Community chat</strong> moves to the <a href="https://discord.gg/xuxtPq43gZ" target="_blank" rel="noopener noreferrer" class="">Agent Router Discord</a>.
The weekly community meeting continues as before.</li>
</ul>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="where-to-go-next">Where to go next<a href="#where-to-go-next" class="hash-link" aria-label="Direct link to Where to go next" title="Direct link to Where to go next" translate="no">​</a></h2>
