<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="ai-ml-fundamentals">AI/ML Fundamentals<a href="#ai-ml-fundamentals" class="hash-link" aria-label="Direct link to AI/ML Fundamentals" title="Direct link to AI/ML Fundamentals" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="context-window">Context Window<a href="#context-window" class="hash-link" aria-label="Direct link to Context Window" title="Direct link to Context Window" translate="no">​</a></h3>
<p>The maximum amount of text (in tokens) that a model can process in a single request.</p>
<p><strong>Related</strong>: <a href="#token" class="">Token</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="prompt">Prompt<a href="#prompt" class="hash-link" aria-label="Direct link to Prompt" title="Direct link to Prompt" translate="no">​</a></h3>
<p>The input text that guides the AI model&#x27;s response, including instructions, context, and specific queries.</p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="temperature">Temperature<a href="#temperature" class="hash-link" aria-label="Direct link to Temperature" title="Direct link to Temperature" translate="no">​</a></h3>
<p>A parameter that controls the randomness/creativity of model outputs, typically ranging from 0 (deterministic) to 1 (more creative).</p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="token">Token<a href="#token" class="hash-link" aria-label="Direct link to Token" title="Direct link to Token" translate="no">​</a></h3>
<p>The basic unit of text processing in LLMs, representing parts of words or characters.</p>
<p><strong>Related</strong>: <a href="#context-window" class="">Context Window</a> · <a href="#token-cost" class="">Token Cost</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="token-cost">Token Cost<a href="#token-cost" class="hash-link" aria-label="Direct link to Token Cost" title="Direct link to Token Cost" translate="no">​</a></h3>
<p>The financial or resource cost associated with token usage in model requests.</p>
<p><strong>Related</strong>: <a href="#token" class="">Token</a> · <a href="#rate-of-llm-token-consumption" class="">Rate of LLM Token Consumption</a></p>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="content--safety">Content & Safety<a href="#content--safety" class="hash-link" aria-label="Direct link to Content & Safety" title="Direct link to Content & Safety" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="content-filtering">Content Filtering<a href="#content-filtering" class="hash-link" aria-label="Direct link to Content Filtering" title="Direct link to Content Filtering" translate="no">​</a></h3>
<p>A mechanism to screen and moderate AI-generated content to ensure compliance with ethical standards, company policies, or regulatory requirements.</p>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="gateway-components">Gateway Components<a href="#gateway-components" class="hash-link" aria-label="Direct link to Gateway Components" title="Direct link to Gateway Components" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="gateway-api-inference-extension">Gateway API Inference Extension<a href="#gateway-api-inference-extension" class="hash-link" aria-label="Direct link to Gateway API Inference Extension" title="Direct link to Gateway API Inference Extension" translate="no">​</a></h3>
<p>A Kubernetes SIG Network extension for Gateway API that provides specialized routing and load balancing capabilities for AI/ML workloads, handling traffic management at the level of inference instances.</p>
<p><strong>Related</strong>: <a href="#inference-instance" class="">Inference Instance</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="genai-gateway">GenAI Gateway<a href="#genai-gateway" class="hash-link" aria-label="Direct link to GenAI Gateway" title="Direct link to GenAI Gateway" translate="no">​</a></h3>
<p>A specialized gateway solution designed to manage, monitor, and route traffic to Generative AI models. It provides capabilities such as load balancing, authorization, token usage monitoring, and integration with multiple model providers.</p>
<p><strong>Related</strong>: <a href="#token" class="">Token</a> · <a href="#model-provider" class="">Model Provider</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="hybrid-genai-gateway">Hybrid GenAI Gateway<a href="#hybrid-genai-gateway" class="hash-link" aria-label="Direct link to Hybrid GenAI Gateway" title="Direct link to Hybrid GenAI Gateway" translate="no">​</a></h3>
<p>A GenAI Gateway configuration that supports both local inference instances and external cloud-based AI models, providing flexibility in deployment and cost management.</p>
<p><strong>Related</strong>: <a href="#genai-gateway" class="">GenAI Gateway</a> · <a href="#inference-instance" class="">Inference Instance</a> · <a href="#model-provider" class="">Model Provider</a></p>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="inference-infrastructure">Inference Infrastructure<a href="#inference-infrastructure" class="hash-link" aria-label="Direct link to Inference Infrastructure" title="Direct link to Inference Infrastructure" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="inference-instance">Inference Instance<a href="#inference-instance" class="hash-link" aria-label="Direct link to Inference Instance" title="Direct link to Inference Instance" translate="no">​</a></h3>
<p>An individual compute resource or container used to run a machine learning model for generating AI outputs (inference).</p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="inference-service">Inference Service<a href="#inference-service" class="hash-link" aria-label="Direct link to Inference Service" title="Direct link to Inference Service" translate="no">​</a></h3>
<p>A service that provides model inference capabilities, including model loading, input processing, inference execution, and output formatting.</p>
<p><strong>Related</strong>: <a href="#inference-instance" class="">Inference Instance</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="model-endpoint">Model Endpoint<a href="#model-endpoint" class="hash-link" aria-label="Direct link to Model Endpoint" title="Direct link to Model Endpoint" translate="no">​</a></h3>
<p>The API endpoint provided by a specific AI model, whether hosted by a cloud provider, open-source solution, or private deployment.</p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="model-provider">Model Provider<a href="#model-provider" class="hash-link" aria-label="Direct link to Model Provider" title="Direct link to Model Provider" translate="no">​</a></h3>
<p>Services providing AI model capabilities through APIs, which can be either first-party providers who develop their own models (like OpenAI, Anthropic) or third-party providers who host other companies&#x27; models (like AWS Bedrock, Azure OpenAI Service).</p>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="model-types--management">Model Types & Management<a href="#model-types--management" class="hash-link" aria-label="Direct link to Model Types & Management" title="Direct link to Model Types & Management" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="fine-tuned-model">Fine-Tuned Model<a href="#fine-tuned-model" class="hash-link" aria-label="Direct link to Fine-Tuned Model" title="Direct link to Fine-Tuned Model" translate="no">​</a></h3>
<p>A version of a base Generative AI model that has been customized for specific tasks or domains using additional training data.</p>
<p><strong>Related</strong>: <a href="#foundation-model" class="">Foundation Model</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="foundation-model">Foundation Model<a href="#foundation-model" class="hash-link" aria-label="Direct link to Foundation Model" title="Direct link to Foundation Model" translate="no">​</a></h3>
<p>Foundation models are large-scale, pre-trained AI models designed to handle a broad range of tasks. They are trained on extensive datasets and can be fine-tuned or adapted to specific use cases.</p>
<p><strong>Related</strong>: <a href="#fine-tuned-model" class="">Fine-Tuned Model</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="model-routing">Model Routing<a href="#model-routing" class="hash-link" aria-label="Direct link to Model Routing" title="Direct link to Model Routing" translate="no">​</a></h3>
<p>A feature in GenAI Gateways that dynamically routes requests to specific models or model versions based on client configuration, use case requirements, or service level agreements.</p>
<p><strong>Related</strong>: <a href="#genai-gateway" class="">GenAI Gateway</a></p>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="usage--analytics">Usage & Analytics<a href="#usage--analytics" class="hash-link" aria-label="Direct link to Usage & Analytics" title="Direct link to Usage & Analytics" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="genai-usage-analytics">GenAI Usage Analytics<a href="#genai-usage-analytics" class="hash-link" aria-label="Direct link to GenAI Usage Analytics" title="Direct link to GenAI Usage Analytics" translate="no">​</a></h3>
<p>The collection and analysis of data regarding how users interact with AI models via the GenAI Gateway, including token usage, request patterns, and latency metrics.</p>
<p><strong>Related</strong>: <a href="#genai-gateway" class="">GenAI Gateway</a> · <a href="#token" class="">Token</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="genai-usage-monitoring">GenAI Usage Monitoring<a href="#genai-usage-monitoring" class="hash-link" aria-label="Direct link to GenAI Usage Monitoring" title="Direct link to GenAI Usage Monitoring" translate="no">​</a></h3>
<p>The tracking of resource consumption across different types of models, including token-based monitoring for LLMs, image resolution and compute resources for LVMs, and combined metrics for multimodal models.</p>
<p><strong>Related</strong>: <a href="#token" class="">Token</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="llm-token-usage-limiting">LLM Token Usage Limiting<a href="#llm-token-usage-limiting" class="hash-link" aria-label="Direct link to LLM Token Usage Limiting" title="Direct link to LLM Token Usage Limiting" translate="no">​</a></h3>
<p>A mechanism to monitor and control the number of tokens processed by an LLM GenAI model, including input, output, and total token limits.</p>
<p><strong>Related</strong>: <a href="#token" class="">Token</a> · <a href="#genai-gateway" class="">GenAI Gateway</a></p>
<h3 class="anchor anchorTargetStickyNavbar_Vzrq" id="rate-of-llm-token-consumption">Rate of LLM Token Consumption<a href="#rate-of-llm-token-consumption" class="hash-link" aria-label="Direct link to Rate of LLM Token Consumption" title="Direct link to Rate of LLM Token Consumption" translate="no">​</a></h3>
<p>The speed at which tokens are consumed by an AI model during processing. This metric is crucial for cost estimation and performance optimization.</p>
<p><strong>Related</strong>: <a href="#token" class="">Token</a></p>
