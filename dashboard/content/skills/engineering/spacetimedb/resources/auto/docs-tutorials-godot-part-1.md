<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="setting-up-the-tutorial-godot-project">Setting up the Tutorial Godot Project<a href="#setting-up-the-tutorial-godot-project" class="hash-link" aria-label="Direct link to Setting up the Tutorial Godot Project" title="Direct link to Setting up the Tutorial Godot Project" translate="no">​</a></h2>
<p>In this section, we will guide you through the process of setting up a Godot Project that will serve as the starting point for our tutorial. By the end of this section, you will have a basic Godot project and be ready to implement the server functionality.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-1-create-a-blank-godot-project">Step 1: Create a Blank Godot Project<a href="#step-1-create-a-blank-godot-project" class="hash-link" aria-label="Direct link to Step 1: Create a Blank Godot Project" title="Direct link to Step 1: Create a Blank Godot Project" translate="no">​</a></h3>
<p>SpacetimeDB supports Godot version <code>4.6.2</code> or later. See <a class="" href="/docs/tutorials/godot/">the overview</a> for more information on specific supported versions.</p>
<p>Open Godot and create a new project by selecting "+ Create" from the Project Manager.</p>
<p>// TODO: THIS IMAGE MUST BE UPDATED
<img decoding="async" loading="lazy" alt="Godot Project Manager" src="/docs/assets/images/part-1-godot-project-manager-0e2efd206642d0e5e421b698f0df6719.png" width="1202" height="887" class="img_sDl7"></p>
<p>For <code>Project Name</code> use <code>blackholio</code>. For <code>Project Location</code> select a directory that you can navigate to via the CLI because we will need to do so in part 2.</p>
<p><img decoding="async" loading="lazy" alt="Create Project" src="/docs/assets/images/part-1-create-project-bf92d437e3056f8b5dbc720fcbaae119.png" width="1202" height="887" class="img_sDl7"></p>
<p>Any Renderer will work.</p>
<p>Click "Create" to generate the blank project.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="import-the-spacetimedb-godot-sdk">Import the SpacetimeDB Godot SDK<a href="#import-the-spacetimedb-godot-sdk" class="hash-link" aria-label="Direct link to Import the SpacetimeDB Godot SDK" title="Direct link to Import the SpacetimeDB Godot SDK" translate="no">​</a></h3>
<p>We will add the SpacetimeDB SDK using NuGet. Godot does not initialize a C# Project when creating a new Godot project, so we need to create a C# Script first to initialize our Godot C# Project.</p>
\<ol\>
<li class=""><strong>Right-click</strong> in the <strong>FileSystem</strong> dock, then select <code>New Script</code>.</li>
<li class="">Select <code>C#</code> in <strong>Lanugage</strong> and name it <code>GameManager</code>. We will use this script later to put the high level initialization and coordination logic for our game.</li>
</ol>
<p><img decoding="async" loading="lazy" alt="Create GameManager Script" src="/docs/assets/images/part-1-game-manager-script-ef45432cbdafcbde694a0181eac9a4a6.png" width="535" height="521" class="img_sDl7"></p>
<ol start="3">
<li class="">Add the <code>SpacetimeDB.ClientSDK</code> <a href="https://www.nuget.org/packages/SpacetimeDB.ClientSDK.Godot/" target="_blank" rel="noopener noreferrer" class="">NuGet package</a> using Visual Studio or Rider <em>NuGet Package Manager</em> or via the .NET CLI:</li>
</ol>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">dotnet</span><span style="color:#F1FA8C"> add</span><span style="color:#F1FA8C"> package</span><span style="color:#F1FA8C"> SpacetimeDB.ClientSDK.Godot</span></span></code></pre>
<p>The SpacetimeDB Godot SDK provides helpful tools for integrating SpacetimeDB into Godot, including a connection update manager which will synchronize your Godot client&#x27;s state with your SpacetimeDB database in accordance with your subscription queries.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="create-a-new-scene">Create a new Scene<a href="#create-a-new-scene" class="hash-link" aria-label="Direct link to Create a new Scene" title="Direct link to Create a new Scene" translate="no">​</a></h3>
\<ol\>
<li class=""><strong>Create a 2D Scene</strong>:<!-- -->
\<ul\>
<li class="">In the <strong>Scene</strong> Dock (usually on the top left), click on <strong>Create Root Node: -> 2D Scene</strong>.</li>
<li class="">Alternatively, you can click the <strong>+</strong> button to add a child node and select a <strong>Node 2D</strong>.</li>
</ul>
</li>
</ol>
<p><img decoding="async" loading="lazy" alt="Create 2D Scene" src="/docs/assets/images/part-1-create-2d-scene-6fb4f9d1897f55bba9c8919c7dafe9b9.png" width="2339" height="1442" class="img_sDl7"></p>
<ol start="2">
<li class="">
<p><strong>Rename the Node</strong>:</p>
\<ul\>
<li class="">In the <strong>Scene</strong> dock, double-click on the newly created node (or <code>right-click -> rename</code>) and rename it to <code>Main</code>.</li>
</ul>
</li>
<li class="">
<p><strong>Attach the GameManager Script</strong>:</p>
\<ul\>
<li class="">Drag and drop the <code>GameManager</code> script from the <strong>Scene</strong> dock onto the <code>Main</code> Node in the <strong>Scene</strong> window.</li>
</ul>
</li>
</ol>
<p>You will see a warning saying <code>This inspector might be out of date. Please build the C# project.</code>. This is because Godot doesn&#x27;t automatically compile our C# project and we need to run the game for the compilation to take place. Let&#x27;s do that.</p>
<ol start="4">
<li class="">
<p><strong>Save current Scene</strong>:</p>
\<ul\>
<li class="">Press <code>Ctrl + S</code> (or <code>Cmd + S</code> on Mac) to save the current scene. Name it <code>main.tscn</code>.</li>
<li class="">Alternatively, go to <code>Scene -> Save Scene As</code>.</li>
</ul>
</li>
<li class="">
<p><strong>Run Project and build C# Project</strong>:</p>
\<ul\>
<li class="">Press <code>F5</code> (or <code>Cmd + B</code> on Mac) to run the project, click on <code>Select Current</code> to select the current scene as the main one.</li>
<li class="">Alternatively, you can click on the play button in the top menu.</li>
</ul>
</li>
</ol>
<p>Our Godot project is all set up! If you press play, it will show a blank screen, but it should start the game without any errors. Now we&#x27;re ready to get started on our SpacetimeDB server module, so we have something to connect to!</p>
