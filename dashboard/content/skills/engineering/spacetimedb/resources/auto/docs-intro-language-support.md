## Server Database Modules

SpacetimeDB modules define your database schema and server-side business
logic. Modules can be written in four languages:

- **[Rust](https://spacetimedb.com/docs/databases)** - High performance, compiled to
  WebAssembly [(Quickstart)](https://spacetimedb.com/docs/quickstarts/rust)
- **[C#](https://spacetimedb.com/docs/databases)** - Great for Unity developers, compiled to
  WebAssembly [(Quickstart)](https://spacetimedb.com/docs/quickstarts/c-sharp)
- **[TypeScript](https://spacetimedb.com/docs/databases)** - Ideal for web developers, runs on
  V8 [(Quickstart)](https://spacetimedb.com/docs/quickstarts/typescript)
- **[C++](https://spacetimedb.com/docs/databases)** - Fits Unreal and C++ workflows, compiled
  to WebAssembly [(Quickstart)](https://spacetimedb.com/docs/quickstarts/c-plus-plus)

## Client SDKs

**Clients** are applications that connect to SpacetimeDB databases. The
`spacetime` CLI tool can automatically generate type-safe client code
for your database.

- **[Rust](https://spacetimedb.com/docs/clients/rust)** -
  [(Quickstart)](https://spacetimedb.com/docs/quickstarts/rust)
- **[C#](https://spacetimedb.com/docs/clients/c-sharp)** -
  [(Quickstart)](https://spacetimedb.com/docs/quickstarts/c-sharp)
- **[TypeScript](https://spacetimedb.com/docs/clients/typescript)** -
  [(Quickstart)](https://spacetimedb.com/docs/quickstarts/typescript)
- **[Unreal Engine](https://spacetimedb.com/docs/clients/unreal)** - C++ and Blueprint support
  [(Tutorial)](https://spacetimedb.com/docs/tutorials/unreal/part-1)

### Unity

SpacetimeDB was designed first and foremost as the backend for
multiplayer Unity games. The C# SDK integrates seamlessly with Unity
projects. Learn more in the [SpacetimeDB Unity
Tutorial](https://spacetimedb.com/docs/tutorials/unity/part-1).
