<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="log-in-to-spacetimedb">Log in to SpacetimeDB<a href="#log-in-to-spacetimedb" class="hash-link" aria-label="Direct link to Log in to SpacetimeDB" title="Direct link to Log in to SpacetimeDB" translate="no">​</a></h2>
<p>SpacetimeDB authenticates users using a GitHub or Google login, to prevent unauthorized access (e.g. somebody else publishing over your module). Log in to SpacetimeDB using:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">spacetime</span><span style="color:#F1FA8C"> login</span></span></code></pre>
<p>This will open a browser and ask you to log in via GitHub or Google. If you forget this step, any commands that require login (like <code>spacetime publish</code>) will ask you to log in when you run them.</p>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="running-spacetimedb-locally">Running SpacetimeDB Locally<a href="#running-spacetimedb-locally" class="hash-link" aria-label="Direct link to Running SpacetimeDB Locally" title="Direct link to Running SpacetimeDB Locally" translate="no">​</a></h2>
<p>To develop SpacetimeDB databases locally, you will need to run the Standalone version of the server.</p>
<p>After installing the SpacetimeDB CLI, run the start command:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">spacetime</span><span style="color:#F1FA8C"> start</span></span></code></pre>
<p>The server listens on port <code>3000</code> by default, customized via <code>--listen-addr</code>.</p>
<p>💡 Standalone mode will run in the foreground.
⚠️ SSL is not supported in standalone mode.</p>
