# Auth Service Redesign

Status Draft In Review

Owner S. Chen

Updated Just now

## Overview

Migrate from session-based authentication to a stateless JWT architecture with refresh token rotation and PKCE support for public clients.

## Architecture

*   •API Gateway validates tokens at the edge
*   •Access tokens: 15min TTL, RS256 signed
*   •Refresh tokens stored in encrypted HttpOnly cookies
*   •Key rotation via /.well-known/jwks.json

## API Contract

POST /v2/auth/token
