## gh issue

Work with GitHub issues.

### General commands

- [gh issue create](https://cli.github.com/manual/gh_issue_create)
- [gh issue list](https://cli.github.com/manual/gh_issue_list)
- [gh issue status](https://cli.github.com/manual/gh_issue_status)

### Targeted commands

- [gh issue close](https://cli.github.com/manual/gh_issue_close)
- [gh issue comment](https://cli.github.com/manual/gh_issue_comment)
- [gh issue delete](https://cli.github.com/manual/gh_issue_delete)
- [gh issue develop](https://cli.github.com/manual/gh_issue_develop)
- [gh issue edit](https://cli.github.com/manual/gh_issue_edit)
- [gh issue lock](https://cli.github.com/manual/gh_issue_lock)
- [gh issue pin](https://cli.github.com/manual/gh_issue_pin)
- [gh issue reopen](https://cli.github.com/manual/gh_issue_reopen)
- [gh issue transfer](https://cli.github.com/manual/gh_issue_transfer)
- [gh issue unlock](https://cli.github.com/manual/gh_issue_unlock)
- [gh issue unpin](https://cli.github.com/manual/gh_issue_unpin)
- [gh issue view](https://cli.github.com/manual/gh_issue_view)

### Options

`-R`, `--repo <[HOST/]OWNER/REPO>`  
Select another repository using the \[HOST/\]OWNER/REPO format

### Examples

``` bash
$ gh issue list
$ gh issue create --label bug
$ gh issue view 123 --web
```
