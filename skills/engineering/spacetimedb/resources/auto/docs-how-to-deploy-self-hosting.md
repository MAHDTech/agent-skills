tocCollapsibleButton_Dk1U">On this page</button></div><div class="theme-doc-markdown markdown">\<header\>\<h1\>Self-hosting</h1></header><p>This tutorial will guide you through setting up SpacetimeDB on an Ubuntu 24.04 server, securing it with HTTPS using Nginx and Let&#x27;s Encrypt, and configuring a systemd service to keep it running.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="prerequisites">Prerequisites<a href="#prerequisites" class="hash-link" aria-label="Direct link to Prerequisites" title="Direct link to Prerequisites" translate="no">​</a></h2>
\<ul\>
<li class="">A fresh Ubuntu 24.04 server (VM or cloud instance of your choice)</li>
<li class="">A domain name (e.g., <code>example.com</code>)</li>
<li class=""><code>sudo</code> privileges on the server</li>
</ul>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-1-create-a-dedicated-user-for-spacetimedb">Step 1: Create a Dedicated User for SpacetimeDB<a href="#step-1-create-a-dedicated-user-for-spacetimedb" class="hash-link" aria-label="Direct link to Step 1: Create a Dedicated User for SpacetimeDB" title="Direct link to Step 1: Create a Dedicated User for SpacetimeDB" translate="no">​</a></h2>
<p>For security purposes, create a dedicated <code>spacetimedb</code> user to run SpacetimeDB:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">sudo</span><span style="color:#F1FA8C"> mkdir</span><span style="color:#F1FA8C"> /stdb</span></span>
<span class="line"><span style="color:#50FA7B">sudo</span><span style="color:#F1FA8C"> useradd</span><span style="color:#BD93F9"> --system</span><span style="color:#F1FA8C"> spacetimedb</span></span>
<span class="line"><span style="color:#50FA7B">sudo</span><span style="color:#F1FA8C"> chown</span><span style="color:#BD93F9"> -R</span><span style="color:#F1FA8C"> spacetimedb:spacetimedb</span><span style="color:#F1FA8C"> /stdb</span></span></code></pre>
<p>Install SpacetimeDB as the new user:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">sudo</span><span style="color:#BD93F9"> -u</span><span style="color:#F1FA8C"> spacetimedb</span><span style="color:#F1FA8C"> bash</span><span style="color:#BD93F9"> -c</span><span style="color:#E9F284"> &#x27;</span><span style="color:#F1FA8C">curl -sSf https://install.spacetimedb.com | sh -s -- --root-dir /stdb --yes</span><span style="color:#E9F284">&#x27;</span></span></code></pre>
<p>Because this installation uses <code>--root-dir /stdb</code>, include <code>--root-dir /stdb</code> when invoking <code>spacetime</code> for this installation. Otherwise, the CLI looks in its default directories rather than <code>/stdb</code>. The service and update commands below include the option for this reason.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-2-create-a-systemd-service-for-spacetimedb">Step 2: Create a Systemd Service for SpacetimeDB<a href="#step-2-create-a-systemd-service-for-spacetimedb" class="hash-link" aria-label="Direct link to Step 2: Create a Systemd Service for SpacetimeDB" title="Direct link to Step 2: Create a Systemd Service for SpacetimeDB" translate="no">​</a></h2>
<p>To ensure SpacetimeDB runs on startup, create a systemd service file:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">sudo</span><span style="color:#F1FA8C"> nano</span><span style="color:#F1FA8C"> /etc/systemd/system/spacetimedb.service</span></span></code></pre>
<p>Add the following content:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#F8F8F2">[Unit]</span></span>
<span class="line"><span style="color:#FF79C6">Description=</span><span style="color:#F8F8F2">SpacetimeDB Server</span></span>
<span class="line"><span style="color:#FF79C6">After=</span><span style="color:#F8F8F2">network.target</span></span>
<span class="line"></span>
<span class="line"><span style="color:#F8F8F2">[Service]</span></span>
<span class="line"><span style="color:#FF79C6">ExecStart=</span><span style="color:#F8F8F2">/stdb/spacetime --root-dir=/stdb start --listen-addr=&#x27;127.0.0.1:3000&#x27;</span></span>
<span class="line"><span style="color:#FF79C6">Restart=</span><span style="color:#BD93F9">always</span></span>
<span class="line"><span style="color:#FF79C6">User=</span><span style="color:#F8F8F2">spacetimedb</span></span>
<span class="line"><span style="color:#FF79C6">WorkingDirectory=</span><span style="color:#F8F8F2">/stdb</span></span>
