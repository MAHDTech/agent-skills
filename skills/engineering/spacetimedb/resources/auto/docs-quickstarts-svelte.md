<div class="steps"><div class="step"><div class="step-content"><strong class="step-title">Create your project</strong><div class="step-description"><p>Run the <code>spacetime dev</code> command to create a new project with a SpacetimeDB module and Svelte client.</p><p>This will start the local SpacetimeDB server, publish your module, generate TypeScript bindings, and start the Svelte development server.</p></div></div><div class="step-code"><pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">spacetime</span><span style="color:#F1FA8C"> dev</span><span style="color:#BD93F9"> --template</span><span style="color:#F1FA8C"> svelte-ts</span></span></code></pre></div></div><div class="step"><div class="step-content"><strong class="step-title">Open your app</strong><div class="step-description"><p>Navigate to <a href="http://localhost:5173" target="_blank" rel="noopener noreferrer" class="">http://localhost:5173</a> to see your app running.</p><p>The template includes a basic Svelte app connected to SpacetimeDB.</p></div></div></div><div class="step"><div class="step-content"><strong class="step-title">Explore the project structure</strong><div class="step-description"><p>Your project contains both server and client code.</p><p>Edit <code>spacetimedb/src/index.ts</code> to add tables and reducers.
