page</button></div><div class="theme-doc-markdown markdown">\<header\>\<h1\>Generating Client Bindings</h1></header><p>Before you can interact with a SpacetimeDB <a class="" href="/docs/databases">database</a> from a client application, you must generate client bindings for your <strong>module</strong>. These bindings create type-safe interfaces that allow your client to query <a class="" href="/docs/tables">tables</a>, invoke <a class="" href="/docs/functions/reducers">reducers</a>, call <a class="" href="/docs/functions/procedures">procedures</a>, and subscribe to <a class="" href="/docs/tables">tables</a>, and/or <a class="" href="/docs/functions/views">views</a>.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="what-are-module-bindings">What Are Module Bindings?<a href="#what-are-module-bindings" class="hash-link" aria-label="Direct link to What Are Module Bindings?" title="Direct link to What Are Module Bindings?" translate="no">​</a></h2>
<p>Module bindings are auto-generated code that mirrors your module&#x27;s schema and functions. They provide:</p>
\<ul\>
<li class=""><strong>Type definitions</strong> matching your module&#x27;s tables and types</li>
<li class=""><strong>Callable functions</strong> for invoking reducers and procedures</li>
<li class=""><strong>Query interfaces</strong> for subscriptions and local cache access</li>
<li class=""><strong>Callback registration</strong> for observing database changes</li>
</ul>
<p>The bindings ensure compile-time type safety between your client and server code, catching errors before runtime.</p>

<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="views">Views<a href="#views" class="hash-link" aria-label="Direct link to Views" title="Direct link to Views" translate="no">​</a></h3>
<p>For each <a class="" href="/docs/functions/views">view</a> in your module, codegen generates:</p>
\<ul\>
<li class=""><strong>Type definitions</strong> for the view&#x27;s return type</li>
<li class=""><strong>Subscription interfaces</strong> for subscribing to view results</li>
<li class=""><strong>Query methods</strong> for accessing cached view results</li>
<li class=""><strong>Update callbacks</strong> when the view has a known primary key</li>
</ul>
<p>Views provide subscribable, computed queries over your data.</p>
<p>See the <a class="" href="/docs/functions/views">Views</a> documentation for details on defining views in your module.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="regenerating-bindings">Regenerating Bindings<a href="#regenerating-bindings" class="hash-link" aria-label="Direct link to Regenerating Bindings" title="Direct link to Regenerating Bindings" translate="no">​</a></h2>
<p>Whenever you modify your module&#x27;s schema or function signatures, regenerate the client bindings by running <code>spacetime generate</code> again. The tool will overwrite the existing generated files with updated code.</p>
<p>If you&#x27;re actively developing and testing changes, consider adding <code>spacetime generate</code> to your build or development workflow.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="using-the-generated-code">Using the Generated Code<a href="#using-the-generated-code" class="hash-link" aria-label="Direct link to Using the Generated Code" title="Direct link to Using the Generated Code" translate="no">​</a></h2>
<p>Once you&#x27;ve generated the bindings, you&#x27;re ready to connect to your database and start interacting with it. See:</p>
\<ul\>
<li class=""><a class="" href="/docs/clients/connection">Connecting to SpacetimeDB</a> for establishing a connection</li>
<li class=""><a class="" href="/docs/clients/api">SDK API Reference</a> for using the generated bindings</li>
<li class="">Language-specific references: <a class="" href="/docs/clients/rust">Rust</a>, <a class="" href="/docs/clients/c-sharp">C#</a>, <a class="" href="/docs/clients/typescript">TypeScript</a>, <a class="" href="/docs/clients/unreal">Unreal</a></li>
</ul>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="troubleshooting">Troubleshooting<a href="#troubleshooting" class="hash-link" aria-label="Direct link to Troubleshooting" title="Direct link to Troubleshooting" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="missing-module-directory">Missing module directory<a href="#missing-module-directory" class="hash-link" aria-label="Direct link to Missing module directory" title="Direct link to Missing module directory" translate="no">​</a></h3>
<p>If <code>spacetime generate</code> fails to find your module, ensure you&#x27;re pointing to the directory containing your module&#x27;s project file (<code>Cargo.toml</code>, <code>.csproj</code>, or <code>package.json</code>).</p>

<p>If your client doesn&#x27;t see new tables or reducers, ensure you&#x27;ve regenerated the bindings after updating your module.
