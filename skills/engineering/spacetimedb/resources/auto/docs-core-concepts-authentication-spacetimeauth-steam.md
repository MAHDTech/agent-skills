type="button" class="clean-btn tocCollapsibleButton_Dk1U">On this page</button></div><div class="theme-doc-markdown markdown">\<header\>\<h1\>Steam Session Ticket Authentication</h1></header><p>SpacetimeAuth supports authentication using Steam&#x27;s Session Ticket system. This allows
users to authenticate with your application using their Steam account.
This method is particularly useful for gaming applications that want to distribute
their applications on Steam.</p>
<p>Once a user authenticates with Steam, SpacetimeAuth will create an account for them
in your SpacetimeAuth project and issue an ID token that your application can use
to authenticate with SpacetimeDB. The ID token will contain claims with information
about the user and game ownership, which you can use for authorization in your application.</p>
<p>The ID token will notably contain the following claims:</p>
\<ul\>
<li class=""><code>sub</code>: The unique identifier for the user in SpacetimeAuth</li>
<li class=""><code>provider_id</code>: The unique identifier for the user in Steam</li>
<li class=""><code>login_method</code>: The authentication provider (in this case, "steam")</li>
<li class=""><code>preferred_username</code>: The user&#x27;s Steam display name</li>
<li class=""><code>picture</code>: The URL to the user&#x27;s Steam avatar (full size)</li>
<li class=""><code>steam_owned_games</code>: An array of all the applications you published owned by the
user on Steam</li>
</ul>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="creating-a-steam-publisher-key">Creating a Steam Publisher Key<a href="#creating-a-steam-publisher-key" class="hash-link" aria-label="Direct link to Creating a Steam Publisher Key" title="Direct link to Creating a Steam Publisher Key" translate="no">​</a></h2>
<p>To use Steam Session Ticket authentication, you need to create a
<a href="https://partner.steamgames.com/doc/webapi_overview/auth" target="_blank" rel="noopener noreferrer" class="">Steam Publisher Key</a>
in the Steamworks dashboard. This key will be used to verify the authenticity of
the session tickets provided by Steam during the authentication process and to
retrieve information about the user&#x27;s owned games.
To create a Steam Publisher Key, follow <a href="https://partner.steamgames.com/doc/webapi_overview/auth#create_publisher_key" target="_blank" rel="noopener noreferrer" class="">Valve&#x27;s official documentation</a></p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="adding-your-steam-publisher-key-and-allowed-app-ids-to-spacetimeauth">Adding your Steam Publisher Key and allowed app IDs to SpacetimeAuth<a href="#adding-your-steam-publisher-key-and-allowed-app-ids-to-spacetimeauth" class="hash-link" aria-label="Direct link to Adding your Steam Publisher Key and allowed app IDs to SpacetimeAuth" title="Direct link to Adding your Steam Publisher Key and allowed app IDs to SpacetimeAuth" translate="no">​</a></h2>
<p>Once you have your Steam Publisher Key, you need to add it to your SpacetimeAuth
project along with the list of allowed app IDs that you want to check for ownership.
You can do this in the SpacetimeAuth dashboard under the "Settings" section.</p>
<p><img decoding="async" loading="lazy" alt="Dashboard settings page" src="/docs/assets/images/steam-dashboard-9a1cdff6ee9ba35639dc6cd45e55de9a.png" width="2544" height="1269" class="img_sDl7"></p>
<p>Any app IDs that will authenticate users through Steam Session Tickets must be added
to the allowed app IDs list in SpacetimeAuth. This ensures that only session tickets
issued for those specific app IDs will be accepted during authentication. This is
an important security measure to prevent unauthorized access using session tickets
from other applications. Make sure to add all the app IDs for the games or DLCs you
want to check ownership for in your application.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="getting-a-steam-session-ticket">Getting a Steam Session Ticket<a href="#getting-a-steam-session-ticket" class="hash-link" aria-label="Direct link to Getting a Steam Session Ticket" title="Direct link to Getting a Steam Session Ticket" translate="no">​</a></h2>
<p>Now that you&#x27;ve set up your Steam Publisher Key and allowed app IDs, you can implement
the client-side logic to get a Steam Session Ticket and authenticate with SpacetimeAuth.
You can use the Steamworks SDK to retrieve a session ticket for the user and then
send it to your backend server for authentication.</p>
<p>Depending on the platform you&#x27;re developing for, the process of obtaining a Steam
Session Ticket may vary.</p>
<p>Here are some resources to help you get started with retrieving a Steam Session Ticket:</p>
\<ul\>
<li class=""><a href="https://partner.steamgames.com/doc/api/ISteamUser#GetAuthTicketForWebApi" target="_blank" rel="noopener noreferrer" class="">Steamworks SDK documentation (C++/Unreal Engine)</a></li>
<li class=""><a href="https://steamworks.github.io/gettingstarted/" target="_blank" rel="noopener noreferrer" class="">Steamworks .Net (C#/Unity)</a></li>
<li class=""><a href="https://godotsteam.com/classes/user/#getauthticketforwebapi" target="_blank" rel="noopener noreferrer" class="">GodotSteam (Godot Engine)</a></li>
<li class=""><a href="https://github.com/ceifa/steamworks.js" target="_blank" rel="noopener noreferrer" class="">Steamworks.js (JavaScript/Node.js)</a></li>
</ul>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="exchanging-the-steam-session-ticket-for-a-spacetimeauth-id-token">Exchanging the Steam Session Ticket for a SpacetimeAuth ID Token<a href="#exchanging-the-steam-session-ticket-for-a-spacetimeauth-id-token" class="hash-link" aria-label="Direct link to Exchanging the Steam Session Ticket for a SpacetimeAuth ID Token" title="Direct link to Exchanging the Steam Session Ticket for a SpacetimeAuth ID Token" translate="no">​</a></h2>
<p>Once you have the Steam Session Ticket, you can send it to the token endpoint of
SpacetimeAuth to exchange it for an ID token that you can use to authenticate with
SpacetimeDB.</p>
<p>Here is an example of how to exchange the Steam Session Ticket using <code>curl</code>:</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">curl</span><span style="color:#BD93F9"> -X</span><span style="color:#F1FA8C"> POST</span><span style="color:#F1FA8C"> https://auth.spacetimedb.com/oidc/token</span><span style="color:#FF79C6"> \</span></span>
<span class="line"><span style="color:#BD93F9">  -H</span><span style="color:#E9F284"> "</span><span style="color:#F1FA8C">content-type: application/x-www-form-urlencoded</span><span style="color:#E9F284">"</span><span style="color:#FF79C6"> \</span></span>
<span class="line"><span style="color:#BD93F9">  -d</span><span style="color:#E9F284"> "</span><span style="color:#F1FA8C">client_id=client_032xAh3p8o3zGzDghXsO5x</span><span style="color:#E9F284">"</span><span style="color:#FF79C6"> \</span></span>
<span class="line"><span style="color:#BD93F9">  -d</span><span style="color:#E9F284"> "</span><span style="color:#F1FA8C">grant_type=urn:spacetimeauth:steam-ticket</span><span style="color:#E9F284">"</span><span style="color:#FF79C6"> \</span></span>
<span class="line"><span style="color:#BD93F9">  -d</span><span style="color:#E9F284"> "</span><span style="color:#F1FA8C">steam_ticket=\<YOUR STEAM TICKET\></span><span style="color:#E9F284">"</span><span style="color:#FF79C6"> \</span></span>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="checking-app-or-dlc-ownership">Checking App or DLC Ownership<a href="#checking-app-or-dlc-ownership" class="hash-link" aria-label="Direct link to Checking App or DLC Ownership" title="Direct link to Checking App or DLC Ownership" translate="no">​</a></h2>
<p>You can check if a user owns a specific app or DLC by inspecting the <code>steam_owned_games</code>
claim in the ID token. This claim contains an array of all the applications you published
that the user owns on Steam. Each entry in the array includes the <code>appid</code> and a boolean
<code>ownsapp</code> indicating whether the user owns the app or not. You can use this information
to implement authorization logic in your application, such as granting access to
certain features or content based on game ownership.</p>
