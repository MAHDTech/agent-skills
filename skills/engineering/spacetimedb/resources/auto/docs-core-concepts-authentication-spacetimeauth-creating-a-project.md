Maincloud. Check out our <a class="" href="/docs/how-to/deploy/maincloud">Deploy to Maincloud</a>
guide to learn how to publish a module.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="1-enabling-spacetimeauth-for-a-module">1. Enabling SpacetimeAuth for a module<a href="#1-enabling-spacetimeauth-for-a-module" class="hash-link" aria-label="Direct link to 1. Enabling SpacetimeAuth for a module" title="Direct link to 1. Enabling SpacetimeAuth for a module" translate="no">​</a></h2>
\<ol\>
<li class="">
<p>Deploy your module to Maincloud if you haven&#x27;t already.</p>
</li>
<li class="">
<p>Navigate to the dashboard of your deployed module on Maincloud:</p>
\<ol\>
<li class="">Click on your profile picture in the top right corner.</li>
<li class="">Select "My profile" from the dropdown menu.</li>
<li class="">Click on the desired module from the list of your deployed modules.
<img decoding="async" loading="lazy" alt="Module dashboard" src="/docs/assets/images/module-dashboard-d5bec015db84530fa9de1083141ea5fa.png" width="2558" height="442" class="img_sDl7"></li>
</ol>
</li>
<li class="">
<p>In the left sidebar, click on "SpacetimeAuth".</p>
<p><img decoding="async" loading="lazy" alt="Module sidebar" src="/docs/assets/images/module-sidebar-2fd9fc2060d5be8d84d222137836a2a8.png" width="425" height="539" class="img_sDl7"></p>
</li>
<li class="">
<p>Click on the "Use SpacetimeAuth" button.
<img decoding="async" loading="lazy" alt="Enable SpacetimeAuth" src="/docs/assets/images/use-spacetimeauth-63317ca4795838042787256e08cc6308.png" width="2558" height="1350" class="img_sDl7"></p>
</li>
</ol>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="2-exploring-the-dashboard">2. Exploring the Dashboard<a href="#2-exploring-the-dashboard" class="hash-link" aria-label="Direct link to 2. Exploring the Dashboard" title="Direct link to 2. Exploring the Dashboard" translate="no">​</a></h2>
<p>The dashboard provides you with multiple tabs to manage different aspects of
your project:</p>
\<ul\>
<li class=""><strong>Overview</strong>: A summary of your project, including a table of recent users.</li>
<li class=""><strong>Clients</strong>: A list of all clients (applications) that can be used to
authenticate in your applications.
A default client is created for you when you create a new project.</li>
<li class=""><strong>Users</strong>: A list of all users in your project, with options to search, filter,
and manage users.</li>
<li class=""><strong>Identity Providers</strong>: A list of all identity providers (e.g. Google, GitHub,
etc.) that can be used to authenticate users in your project.</li>
<li class=""><strong>Customization</strong>: Live editor to customize colors, logos, and authentication methods.</li>
</ul>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="4-next-steps">4. Next Steps<a href="#4-next-steps" class="hash-link" aria-label="Direct link to 4. Next Steps" title="Direct link to 4. Next Steps" translate="no">​</a></h2>
<p>Now that you have created a SpacetimeAuth project, you can start configuring it
