<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="registering-handlers-to-routes">Registering Handlers to Routes<a href="#registering-handlers-to-routes" class="hash-link" aria-label="Direct link to Registering Handlers to Routes" title="Direct link to Registering Handlers to Routes" translate="no">​</a></h2>

<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="strict-routing">Strict Routing<a href="#strict-routing" class="hash-link" aria-label="Direct link to Strict Routing" title="Direct link to Strict Routing" translate="no">​</a></h3>
<p>SpacetimeDB uses strict routing, meaning that a request must match a path exactly in order to be routed to that handler. Trailing slashes are significant.</p>
