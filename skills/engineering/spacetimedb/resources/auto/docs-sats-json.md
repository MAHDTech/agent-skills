tocCollapsibleButton_Dk1U">On this page</button></div><div class="theme-doc-markdown markdown">\<header\>\<h1\>SATS-JSON Data Format</h1></header>
<p>The Spacetime Algebraic Type System JSON format defines how Spacetime <code>AlgebraicType</code>s and <code>AlgebraicValue</code>s are encoded as JSON. Algebraic types and values are JSON-encoded for transport via the <a class="" href="/docs/http/database">HTTP Databases API</a> and the WebSocket text protocol. Note that SATS-JSON is not self-describing, and so a SATS value represented in JSON requires knowing the value&#x27;s schema to meaningfully understand it - for example, it&#x27;s not possible to tell whether a JSON object with a single field is a <code>ProductValue</code> with one element or a <code>SumValue</code>.</p>

<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="algebraicvalue"><code>AlgebraicValue</code><a href="#algebraicvalue" class="hash-link" aria-label="Direct link to algebraicvalue" title="Direct link to algebraicvalue" translate="no">​</a></h3>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#F8F8F2">SumValue | ProductValue | BuiltinValue</span></span></code></pre>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="sumvalue"><code>SumValue</code><a href="#sumvalue" class="hash-link" aria-label="Direct link to sumvalue" title="Direct link to sumvalue" translate="no">​</a></h3>
<p>An instance of a <a href="#sumtype" class=""><code>SumType</code></a>. <code>SumValue</code>s are encoded as a JSON object with a single key, a non-negative integer tag which identifies the variant. The value associated with this key is the variant data. Variants which hold no data will have an empty array as their value.</p>
<p>The tag is an index into the <a href="#sumtype" class=""><code>SumType.variants</code></a> array of the value&#x27;s <a href="#sumtype" class=""><code>SumType</code></a>.</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#F8F8F2">{</span></span>
<span class="line"><span style="color:#8BE9FE">    "</span><span style="color:#8BE9FD">\<tag\></span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span> </span><span style="color:#FF5555;font-style:italic;text-decoration:underline">AlgebraicValue</span></span>
<span class="line"><span style="color:#F8F8F2">}</span></span></code></pre>
<p>The tag may also be the name of one of the variants.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="productvalue"><code>ProductValue</code><a href="#productvalue" class="hash-link" aria-label="Direct link to productvalue" title="Direct link to productvalue" translate="no">​</a></h3>
<p>An instance of a <a href="#producttype" class=""><code>ProductType</code></a>. <code>ProductValue</code>s are encoded as JSON arrays. Each element of the <code>ProductValue</code> array is of the type of the corresponding index in the <a href="#producttype" class=""><code>ProductType.elements</code></a> array of the value&#x27;s <a href="#producttype" class=""><code>ProductType</code></a>.</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#F8F8F2">array\<AlgebraicValue\></span></span></code></pre>
<p><code>ProductValue</code>s may also be encoded as a JSON object with the keys as the field
names of the <code>ProductValue</code> and the values as the corresponding
<code>AlgebraicValue</code>s.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="builtinvalue"><code>BuiltinValue</code><a href="#builtinvalue" class="hash-link" aria-label="Direct link to builtinvalue" title="Direct link to builtinvalue" translate="no">​</a></h3>
<p>An instance of a <a href="#builtintype" class=""><code>BuiltinType</code></a>. <code>BuiltinValue</code>s are encoded as JSON values of corresponding types.</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#F8F8F2">boolean | number | string | array\<AlgebraicValue\> | map\<AlgebraicValue, AlgebraicValue\></span></span></code></pre>
<table><thead><tr><th><a href="#builtintype" class=""><code>BuiltinType</code></a></th><th>JSON type</th></tr></thead>\<tbody\><tr><td><code>Bool</code></td><td><code>boolean</code></td></tr><tr><td>Integer types</td><td><code>number</code></td></tr><tr><td>Float types</td><td><code>number</code></td></tr><tr><td><code>String</code></td><td><code>string</code></td></tr><tr><td>Array types</td><td><code>array\<AlgebraicValue\></code></td></tr><tr><td>Map types</td><td><code>map\<AlgebraicValue, AlgebraicValue\></code></td></tr></tbody></table>
<p>All SATS integer types are encoded as JSON <code>number</code>s, so values of 64-bit and 128-bit integer types may lose precision when encoding values larger than 2⁵².</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="types">Types<a href="#types" class="hash-link" aria-label="Direct link to Types" title="Direct link to Types" translate="no">​</a></h2>
<p>All SATS types are JSON-encoded by converting them to an <code>AlgebraicValue</code>, then JSON-encoding that meta-value.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="at-a-glance-1">At a glance<a href="#at-a-glance-1" class="hash-link" aria-label="Direct link to At a glance" title="Direct link to At a glance" translate="no">​</a></h3>
<table><thead><tr><th>Type</th><th>Description</th></tr></thead>\<tbody\><tr><td><a href="#algebraictype" class=""><code>AlgebraicType</code></a></td><td>Any SATS type.</td></tr><tr><td><a href="#sumtype" class=""><code>SumType</code></a></td><td>Sum types, i.e. tagged unions.</td></tr><tr><td><a href="#producttype" class=""><code>ProductType</code></a></td><td>Product types, i.e. structures.</td></tr><tr><td><a href="#builtintype" class=""><code>BuiltinType</code></a></td><td>Built-in and primitive types, including booleans, numbers, strings, arrays and maps.</td></tr><tr><td><a href="#algebraictyperef" class=""><code>AlgebraicTypeRef</code></a></td><td>An indirect reference to a type, used to implement recursive types.</td></tr></tbody></table>
<h4 class="anchor anchorTargetStickyNavbar_Y_NL" id="algebraictype"><code>AlgebraicType</code><a href="#algebraictype" class="hash-link" aria-label="Direct link to algebraictype" title="Direct link to algebraictype" translate="no">​</a></h4>
<p><code>AlgebraicType</code> is the most general meta-type in the Spacetime Algebraic Type System. Any SATS type can be represented as an <code>AlgebraicType</code>. <code>AlgebraicType</code> is encoded as a tagged union, with variants for <a href="#sumtype" class=""><code>SumType</code></a>, <a href="#producttype" class=""><code>ProductType</code></a>, <a href="#builtintype" class=""><code>BuiltinType</code></a> and <a href="#algebraictyperef" class=""><code>AlgebraicTypeRef</code></a>.</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#F8F8F2">{ </span><span style="color:#8BE9FE">"</span><span style="color:#8BE9FD">Sum</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span> </span><span style="color:#FF5555;font-style:italic;text-decoration:underline">SumType</span><span style="color:#F8F8F2"> }</span></span>
<span class="line"><span style="color:#F8F8F2">| { </span><span style="color:#8BE9FE">"</span><span style="color:#8BE9FD">Product</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span> </span><span style="color:#FF5555;font-style:italic;text-decoration:underline">ProductType</span><span style="color:#F8F8F2"> }</span></span>
<span class="line"><span style="color:#F8F8F2">| { </span><span style="color:#8BE9FE">"</span><span style="color:#8BE9FD">Builtin</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span> </span><span style="color:#FF5555;font-style:italic;text-decoration:underline">BuiltinType</span><span style="color:#F8F8F2"> }</span></span>
<span class="line"><span style="color:#F8F8F2">| { </span><span style="color:#8BE9FE">"</span><span style="color:#8BE9FD">Ref</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span> </span><span style="color:#FF5555;font-style:italic;text-decoration:underline">AlgebraicTypeRef</span><span style="color:#F8F8F2"> }</span></span></code></pre>
<h4 class="anchor anchorTargetStickyNavbar_Y_NL" id="sumtype"><code>SumType</code><a href="#sumtype" class="hash-link" aria-label="Direct link to sumtype" title="Direct link to sumtype" translate="no">​</a></h4>
<p>The meta-type <code>SumType</code> represents sum types, also called tagged unions or Rust <code>enum</code>s. A sum type has some number of variants, each of which has an <code>AlgebraicType</code> of variant data, and an optional string discriminant. For each instance, exactly one variant will be active. The instance will contain only that variant&#x27;s data.</p>
<p>A <code>SumType</code> with zero variants is called an empty type or never type because it is impossible to construct an instance.</p>
<p>Instances of <code>SumType</code>s are <a href="#sumvalue" class=""><code>SumValue</code>s</a>, and store a tag which identifies the active variant.</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#6272A4">// SumType:</span></span>
<span class="line"><span style="color:#F8F8F2">{</span></span>

<span class="line"><span style="color:#F8F8F2">}</span></span>
<span class="line"></span>
<span class="line"><span style="color:#6272A4">// SumTypeVariant:</span></span>
<span class="line"><span style="color:#F8F8F2">{</span></span>
<span class="line"><span style="color:#8BE9FE">    "</span><span style="color:#8BE9FD">algebraic_type</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span> </span><span style="color:#FF5555;font-style:italic;text-decoration:underline">AlgebraicType</span><span style="color:#F8F8F2">,</span></span>
<span class="line"><span style="color:#8BE9FE">    "</span><span style="color:#8BE9FD">name</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span style="color:#F8F8F2"> { </span><span style="color:#8BE9FE">"</span><span style="color:#8BE9FD">some</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span> </span><span style="color:#FF5555;font-style:italic;text-decoration:underline">string</span><span style="color:#F8F8F2"> } </span><span style="color:#FF5555;font-style:italic;text-decoration:underline">|</span><span style="color:#F8F8F2"> { </span><span style="color:#8BE9FE">"</span><span style="color:#8BE9FD">none</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span style="color:#F8F8F2"> [] }</span></span>
<span class="line"><span style="color:#F8F8F2">}</span></span></code></pre>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="producttype"><code>ProductType</code><a href="#producttype" class="hash-link" aria-label="Direct link to producttype" title="Direct link to producttype" translate="no">​</a></h3>
<p>The meta-type <code>ProductType</code> represents product types, also called structs or tuples. A product type has some number of fields, each of which has an <code>AlgebraicType</code> of field data, and an optional string field name. Each instance will contain data for all of the product type&#x27;s fields.</p>
<p>A <code>ProductType</code> with zero fields is called a unit type because it has a single instance, the unit, which is empty.</p>
<p>Instances of <code>ProductType</code>s are <a href="#productvalue" class=""><code>ProductValue</code>s</a>, and store an array of field data.</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#6272A4">// ProductType:</span></span>

<span class="line"><span style="color:#F8F8F2">}</span></span>
<span class="line"></span>
<span class="line"><span style="color:#6272A4">// ProductTypeElement:</span></span>
<span class="line"><span style="color:#F8F8F2">{</span></span>
<span class="line"><span style="color:#8BE9FE">    "</span><span style="color:#8BE9FD">algebraic_type</span><span style="color:#8BE9FE">"</span><span style="color:#FF79C6">:</span><span> </span><span style="color:#FF5555;font-style:italic;text-decoration:underline">AlgebraicType</span><span style="color:#F8F8F2">,</span></span>

<span class="line"><span style="color:#F8F8F2">}</span></span></code></pre>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="builtintype"><code>BuiltinType</code><a href="#builtintype" class="hash-link" aria-label="Direct link to builtintype" title="Direct link to builtintype" translate="no">​</a></h3>
<p>The meta-type <code>BuiltinType</code> represents SATS primitive types: booleans, integers, floating-point numbers, strings, arrays and maps. <code>BuiltinType</code> is encoded as a tagged union, with a variant for each SATS primitive type.</p>
<p>SATS integer types are identified by their signedness and width in bits. SATS supports the same set of integer types as Rust, i.e. 8, 16, 32, 64 and 128-bit signed and unsigned integers.</p>
<p>SATS floating-point number types are identified by their width in bits. SATS supports 32 and 64-bit floats, which correspond to <a href="https://en.wikipedia.org/wiki/IEEE_754" target="_blank" rel="noopener noreferrer" class="">IEEE 754</a> single- and double-precision binary floats, respectively.</p>
<p>SATS array and map types are homogeneous, meaning that each array has a single element type to which all its elements must conform, and each map has a key type and a value type to which all of its keys and values must conform.</p>
