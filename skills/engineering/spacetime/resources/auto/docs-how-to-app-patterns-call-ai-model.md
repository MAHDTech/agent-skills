class="admonitionContent_STxx"><p>You need a module and a client connected to it, and an API key from the provider of the AI model you want to use. If you don&#x27;t have a module yet, follow the <a class="" href="/docs/">quickstart</a> for your language first.</p><p>There&#x27;s no C++ version of this guide yet.</p></div></div>
<p>In this guide, you&#x27;ll let clients ask an AI model, such as a large language model (LLM), to generate text, for example a reply from a character in your game. The request goes through your module, so your provider API key never reaches the client. You&#x27;ll use a <a class="" href="/docs/functions/procedures">procedure</a> to make the HTTP request, an <a class="" href="/docs/databases/environment-variables">environment variable</a> to store the API key, and a private table to limit how often each player can call the model.</p>
<p>The examples cover Anthropic, OpenAI and Google. Other providers work the same way: only the request and the way you read the reply change.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="how-it-works">How it works<a href="#how-it-works" class="hash-link" aria-label="Direct link to How it works" title="Direct link to How it works" translate="no">​</a></h2>
\<ul\>
<li class="">An <code>AI_API_KEY</code> environment variable stores your provider API key on the database. You set it when you publish.</li>
<li class="">A <code>call_model</code> function sends the prompt to your provider and returns the generated text. It&#x27;s the only provider-specific code.</li>
<li class="">A <code>generate_text</code> procedure checks the prompt and the caller&#x27;s cooldown, calls <code>call_model</code>, and returns the text, or an error message, to the client.</li>
<li class="">A private <code>model_usage</code> table records when each player last called the model.</li>
</ul>
<p>The model is called from a procedure, not a reducer. Reducers can&#x27;t make HTTP requests, because they run inside a transaction. A procedure can, and it doesn&#x27;t hold a transaction open while it waits for the model, which can take several seconds.</p>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="generate-text-for-a-client">Generate text for a client<a href="#generate-text-for-a-client" class="hash-link" aria-label="Direct link to Generate text for a client" title="Direct link to Generate text for a client" translate="no">​</a></h2>
<p>Add a <code>generate_text</code> procedure that clients call with their prompt. Every call costs you money, so the procedure first rejects prompts that are empty or too long, and players who called it less than 5 seconds ago. It checks the cooldown in a short transaction, then calls <code>call_model</code> outside of it with the API key from <code>ctx.env</code>.</p>
<p>The procedure returns a <code>GeneratedText</code> value with two fields: <code>text</code> holds the generated text, and <code>error</code> explains what went wrong, or is empty on success. Returning errors this way, instead of throwing, means clients get the same kind of result whichever language your module is written in.</p>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="whats-next">What&#x27;s next?<a href="#whats-next" class="hash-link" aria-label="Direct link to What&#x27;s next?" title="Direct link to What&#x27;s next?" translate="no">​</a></h2>
<p>You now have a module that generates text with an AI model on behalf of its clients:</p>
\<ul\>
<li class="">A <code>call_model</code> function holds the only provider-specific code, so switching providers means replacing one function.</li>
<li class="">The API key lives in an environment variable on the database, never on the client.</li>
<li class="">The <code>generate_text</code> procedure rejects oversized prompts and players who call it too often, calls the model outside any transaction, and returns errors as values that every client can read.</li>
</ul>
<p>To allow each player a number of calls per time window, such as 10 per minute, instead of one call every 5 seconds, use the <a href="https://spacetimedb.com/submodules/rate-limit" target="_blank" rel="noopener noreferrer" class="">Rate Limit submodule</a> in a TypeScript module. It&#x27;s a package you add to your module.</p>
<p>To learn more about the features used here, see <a class="" href="/docs/functions/procedures">Procedures</a>, <a class="" href="/docs/databases/environment-variables">Environment Variables</a> and <a class="" href="/docs/tables/access-permissions">Access Permissions</a>.</p>
<p>To call the model from a separate program instead, with your provider&#x27;s SDK and streaming replies, see <a class="" href="/docs/how-to/app-patterns/call-ai-model-sidecar">Call an AI model from a sidecar</a>.</p>
