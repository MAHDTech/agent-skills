<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="best-practices">Best Practices<a href="#best-practices" class="hash-link" aria-label="Direct link to Best Practices" title="Direct link to Best Practices" translate="no">​</a></h2>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="log-levels">Log Levels<a href="#log-levels" class="hash-link" aria-label="Direct link to Log Levels" title="Direct link to Log Levels" translate="no">​</a></h3>
<p>Use appropriate log levels for different types of messages:</p>
\<ul\>
<li class=""><strong>Error</strong>: Use for actual errors that prevent operations from completing</li>
<li class=""><strong>Warn</strong>: Use for potentially problematic situations that don&#x27;t prevent execution</li>
<li class=""><strong>Info</strong>: Use for important application events (user actions, state changes)</li>
<li class=""><strong>Debug</strong>: Use for detailed diagnostic information useful during development</li>
<li class=""><strong>Trace</strong>: Use for very detailed diagnostic information (typically disabled in production)</li>
</ul>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="performance-considerations">Performance Considerations<a href="#performance-considerations" class="hash-link" aria-label="Direct link to Performance Considerations" title="Direct link to Performance Considerations" translate="no">​</a></h3>
\<ul\>
<li class="">Logging has minimal overhead, but excessive logging can impact performance</li>
<li class="">Avoid logging in tight loops or high-frequency operations</li>
<li class="">Consider using debug/trace logs for verbose output that can be filtered in production</li>
</ul>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="privacy-and-security">Privacy and Security<a href="#privacy-and-security" class="hash-link" aria-label="Direct link to Privacy and Security" title="Direct link to Privacy and Security" translate="no">​</a></h3>
\<ul\>
<li class="">Logs are only visible to the database owner, not to clients</li>
<li class="">Avoid logging sensitive information like passwords or authentication tokens</li>
<li class="">Be mindful of personally identifiable information (PII) in logs</li>
