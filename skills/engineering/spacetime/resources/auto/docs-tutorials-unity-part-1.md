<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="setting-up-the-tutorial-unity-project">Setting up the Tutorial Unity Project<a href="#setting-up-the-tutorial-unity-project" class="hash-link" aria-label="Direct link to Setting up the Tutorial Unity Project" title="Direct link to Setting up the Tutorial Unity Project" translate="no">​</a></h2>
<p>In this section, we will guide you through the process of setting up a Unity Project that will serve as the starting point for our tutorial. By the end of this section, you will have a basic Unity project and be ready to implement the server functionality.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-1-create-a-blank-unity-project">Step 1: Create a Blank Unity Project<a href="#step-1-create-a-blank-unity-project" class="hash-link" aria-label="Direct link to Step 1: Create a Blank Unity Project" title="Direct link to Step 1: Create a Blank Unity Project" translate="no">​</a></h3>
<p>SpacetimeDB supports Unity version <code>2022.3.32f1</code> or later. See <a class="" href="/docs/tutorials/unity/">the overview</a> for more information on specific supported versions.</p>

<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="import-the-spacetimedb-unity-sdk">Import the SpacetimeDB Unity SDK<a href="#import-the-spacetimedb-unity-sdk" class="hash-link" aria-label="Direct link to Import the SpacetimeDB Unity SDK" title="Direct link to Import the SpacetimeDB Unity SDK" translate="no">​</a></h3>
<p>Add the SpacetimeDB Unity Package using the Package Manager. Open the Package Manager window by clicking on Window -> Package Manager. Click on the + button in the top left corner of the window and select "Add package from git URL". Enter the following URL and click Add.</p>
<pre tabindex="0" class="codeBlockStandalone_LlrK thin-scrollbar codeBlockContainer_hFbQ theme-code-block" style="--prism-color:#bfc7d5;--prism-background-color:#292d3e"><code class="codeBlockLines_JqGU"><span class="line"><span style="color:#50FA7B">https://github.com/clockworklabs/com.clockworklabs.spacetimedbsdk.git</span></span></code></pre>
<p>The SpacetimeDB Unity SDK provides helpful tools for integrating SpacetimeDB into Unity, including a network manager which will synchronize your Unity client&#x27;s state with your SpacetimeDB database in accordance with your subscription queries.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="create-the-gamemanager-script">Create the GameManager Script<a href="#create-the-gamemanager-script" class="hash-link" aria-label="Direct link to Create the GameManager Script" title="Direct link to Create the GameManager Script" translate="no">​</a></h3>
\<ol\>
<li class="">In the Unity <strong>Project</strong> window, go to the folder where you want to keep your scripts (e.g., <code>Scripts</code> folder).</li>
<li class=""><strong>Right-click</strong> in the folder, then select <code>Create > C# Script</code> or in Unity 6 <code>MonoBehavior Script</code>.</li>
<li class="">Name the script <code>GameManager</code>.</li>
</ol>
<p>The <code>GameManager</code> script will be where we will put the high level initialization and coordination logic for our game.</p>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="add-the-gamemanager-to-the-scene">Add the GameManager to the Scene<a href="#add-the-gamemanager-to-the-scene" class="hash-link" aria-label="Direct link to Add the GameManager to the Scene" title="Direct link to Add the GameManager to the Scene" translate="no">​</a></h3>
\<ol\>
<li class="">
<p><strong>Create an Empty GameObject</strong>:</p>
\<ul\>
<li class="">Go to the top menu and select <strong>GameObject > Create Empty</strong>.</li>
<li class="">Alternatively, right-click in the <strong>Hierarchy</strong> window and select <strong>Create Empty</strong>.</li>
</ul>
</li>
<li class="">
<p><strong>Rename the GameObject</strong>:</p>
\<ul\>
<li class="">In the <strong>Inspector</strong>, click on the GameObject’s name at the top and rename it to <code>GameManager</code>.</li>
</ul>
</li>
<li class="">
<p><strong>Attach the GameManager Script</strong>:</p>
\<ul\>
<li class="">Drag and drop the <code>GameManager</code> script from the <strong>Project</strong> window onto the <code>GameManager</code> GameObject in the <strong>Hierarchy</strong> window.</li>
<li class="">Alternatively, in the <strong>Inspector</strong>, click <strong>Add Component</strong>, search for <code>GameManager</code>, and select it.</li>
</ul>
</li>
</ol>
<h3 class="anchor anchorTargetStickyNavbar_Y_NL" id="add-the-spacetimedb-network-manager">Add the SpacetimeDB Network Manager<a href="#add-the-spacetimedb-network-manager" class="hash-link" aria-label="Direct link to Add the SpacetimeDB Network Manager" title="Direct link to Add the SpacetimeDB Network Manager" translate="no">​</a></h3>
<p>The <code>SpacetimeDBNetworkManager</code> is a simple script which hooks into the Unity <code>Update</code> loop in order to drive the sending and processing of messages between your client and SpacetimeDB. You don&#x27;t have to interact with this script, but it must be present on a single GameObject which is in the scene in order for it to facilitate the processing of messages.</p>
<p>When you build a new connection to SpacetimeDB, that connection will be added to and managed by the <code>SpacetimeDBNetworkManager</code> automatically.</p>
<p>The SDK also resets its own internal static Unity state when entering Play Mode, including projects that disable Domain Reloading in Unity&#x27;s Enter Play Mode Options. Your own static fields and singleton references are still your responsibility.</p>
<p>Click on the <code>GameManager</code> object in the scene and click <strong>Add Component</strong>. Search for and select the <code>SpacetimeDBNetworkManager</code> to add it to your <code>GameManager</code> object.</p>
<p>Our Unity project is all set up! If you press play, it will show a blank screen, but it should start the game without any errors. Now we&#x27;re ready to get started on our SpacetimeDB server module, so we have something to connect to!</p>
