class="admonitionContent_STxx"><p>You need a module and a client connected to it, and an <a href="https://platform.openai.com/api-keys" target="_blank" rel="noopener noreferrer" class="">OpenAI API key</a>. If you don&#x27;t have a module yet, follow the <a class="" href="/docs/">quickstart</a> for your language first.</p><p>There&#x27;s no C++ version of this guide yet.</p></div></div>
<p>In this guide, you&#x27;ll let players pick a username that no one else has, ignoring case, and reject names that are offensive. You&#x27;ll use a <a class="" href="/docs/tables/constraints#unique-columns">unique column</a> to keep names unique, a profanity library to catch swear words, and OpenAI&#x27;s <a href="https://developers.openai.com/api/docs/guides/moderation" target="_blank" rel="noopener noreferrer" class="">moderation API</a> to catch hateful or harassing names. The API is called from a <a class="" href="/docs/functions/procedures">procedure</a>, with an API key stored in an <a class="" href="/docs/databases/environment-variables">environment variable</a>.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="how-it-works">How it works<a href="#how-it-works" class="hash-link" aria-label="Direct link to How it works" title="Direct link to How it works" translate="no">​</a></h2>
\<ul\>
<li class="">A public <code>player</code> table holds each player&#x27;s <code>name</code>, as they typed it, and its lowercase form, <code>name_key</code>. <code>name_key</code> is unique, so "Bob" and "bob" can&#x27;t both exist. A player only gets a row once they&#x27;ve picked a valid name, so the table also tells you who&#x27;s ready to play.</li>
<li class="">A <code>set_username</code> procedure checks a name in three steps, cheapest first:<!-- -->
\<ol\>
<li class="">The name must be 3 to 20 letters, digits or underscores.</li>
<li class="">A profanity library rejects swear words and, depending on the library, disguised spellings that use digits in place of letters. It runs inside your module, so it&#x27;s instant and free.</li>
<li class="">The OpenAI moderation API rejects names that its model judges hateful, harassing, sexual or violent.</li>
</ol>
</li>
<li class="">A private <code>name_attempt</code> table records when each player last asked for a name, so a player can&#x27;t flood the moderation API with requests.</li>
<li class="">An <code>OPENAI_API_KEY</code> environment variable stores your API key on the database.</li>
</ul>
<p>The two content checks cover different things. A word list only knows the words on it, but it catches swearing, which isn&#x27;t one of the moderation API&#x27;s categories. The moderation API judges what a name means, so it can reject a hateful or threatening name that uses no swear words at all.</p>
<p><code>set_username</code> is a procedure, not a reducer, because reducers can&#x27;t make HTTP requests. The procedure calls the moderation API outside of any transaction, and only opens short transactions to read and write tables.</p>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="set-a-username">Set a username<a href="#set-a-username" class="hash-link" aria-label="Direct link to Set a username" title="Direct link to Set a username" translate="no">​</a></h2>
<p>Add the <code>set_username</code> procedure that clients call with the name they want. Players call it both to pick their first name and to change it later.</p>
<p>The procedure runs the checks in order of cost, and stops at the first one that fails:</p>
\<ol\>
<li class="">It checks the name&#x27;s format, then runs the word list on the key, with underscores read as spaces so the library sees <code>bad_word</code> as two words. The moderation API later gets the same text.</li>
<li class="">In a short transaction, it rejects names that another player already has, then rejects players who asked for a name less than 5 seconds ago. A taken name doesn&#x27;t count towards the limit, because it never reaches the API.</li>
<li class="">It calls the moderation API, outside of any transaction.</li>
<li class="">In a second transaction, it checks again that the name is free, because another player may have taken it while the API was answering, and saves it.</li>
</ol>
<p>The procedure returns an empty string on success, or a message that explains what went wrong. Returning errors as values, instead of throwing, means clients get the same kind of result whichever language your module is written in.</p>

<p>When the moderation API can&#x27;t be reached, or answers with an error, the procedure refuses the name and asks the player to try again later. It logs the details for you, and sends players a generic message. If you&#x27;d rather keep accepting names during an OpenAI outage, log the error and continue instead: the name then only passes the word list.</p>
<p>The unique constraint on <code>name_key</code> is the final guarantee: even if your code had a bug, the database would never store two rows with the same key.</p>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="whats-next">What&#x27;s next?<a href="#whats-next" class="hash-link" aria-label="Direct link to What&#x27;s next?" title="Direct link to What&#x27;s next?" translate="no">​</a></h2>
<p>You now have usernames that are unique and checked before anyone sees them:</p>
\<ul\>
<li class="">A unique <code>name_key</code> column keeps names unique, ignoring case.</li>
<li class="">A profanity library rejects swear words for free, inside your module.</li>
<li class="">The OpenAI moderation API rejects names that its model judges harmful, even without swear words, with the API key stored in an environment variable.</li>
<li class="">The <code>set_username</code> procedure runs the cheap checks first, calls the API outside any transaction, and returns errors as values that every client can read.</li>
<li class="">Only players with a name have a <code>player</code> row, so reducers that need one start with <code>require_player</code>.</li>
</ul>
<p>To learn more about the features used here, see <a class="" href="/docs/tables/constraints">Constraints</a>, <a class="" href="/docs/functions/procedures">Procedures</a> and <a class="" href="/docs/databases/environment-variables">Environment Variables</a>.</p>
<p>To allow each player a number of name requests per time window, such as 5 per minute, instead of one request every 5 seconds, use the <a href="https://spacetimedb.com/submodules/rate-limit" target="_blank" rel="noopener noreferrer" class="">Rate Limit submodule</a> in a TypeScript module. It&#x27;s a package you add to your module.</p>
<p>To call other web services from your module the same way, see <a class="" href="/docs/how-to/app-patterns/call-ai-model">Call an AI model from your module</a>.</p>
