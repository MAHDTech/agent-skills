markdown">\<header\>\<h1\>Railway</h1></header><p>Railway is a hosted platform for deploying infrastructure and application services. If you want to run SpacetimeDB without managing your own VM, the official Railway template is a quick way to get started.</p>
<p>The template deploys the first-party <code>clockworklabs/spacetime</code> image, exposes port <code>3000</code>, and provisions persistent storage at <code>/stdb</code>. Once the service is running, you can publish one or more databases to it with the SpacetimeDB CLI.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="prerequisites">Prerequisites<a href="#prerequisites" class="hash-link" aria-label="Direct link to Prerequisites" title="Direct link to Prerequisites" translate="no">​</a></h2>
\<ol\>
<li class="">A <a href="https://railway.com/" target="_blank" rel="noopener noreferrer" class="">Railway account</a></li>
<li class="">The SpacetimeDB CLI installed: <a href="https://spacetimedb.com/install" target="_blank" rel="noopener noreferrer" class="">Install SpacetimeDB</a></li>
<li class="">A SpacetimeDB module project ready to publish</li>
</ol>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-1-deploy-the-railway-template">Step 1: Deploy the Railway template<a href="#step-1-deploy-the-railway-template" class="hash-link" aria-label="Direct link to Step 1: Deploy the Railway template" title="Direct link to Step 1: Deploy the Railway template" translate="no">​</a></h2>
<p>Open the official deployment template:</p>
<p><a href="https://railway.com/deploy/spacetimedb?utm_medium=integration&utm_source=button&utm_campaign=spacetimedb" target="_blank" rel="noopener noreferrer" class=""><img decoding="async" loading="lazy" src="https://railway.com/button.svg" alt="Deploy on Railway" class="img_sDl7"></a></p>
<p>Then:</p>
\<ol\>
<li class="">Click <strong>Deploy Now</strong>.</li>
<li class="">Create a new Railway project or choose an existing one.</li>
<li class="">Wait for the deployment to finish.</li>
<li class="">In Railway, open your service and copy its public domain or attach a custom domain.</li>
</ol>
<p>That domain is the base URL your CLI and clients will use to connect to this SpacetimeDB instance.</p>
<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-2-add-the-railway-deployment-to-your-cli">Step 2: Add the Railway deployment to your CLI<a href="#step-2-add-the-railway-deployment-to-your-cli" class="hash-link" aria-label="Direct link to Step 2: Add the Railway deployment to your CLI" title="Direct link to Step 2: Add the Railway deployment to your CLI" translate="no">​</a></h2>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="step-3-publish-your-database">Step 3: Publish your database<a href="#step-3-publish-your-database" class="hash-link" aria-label="Direct link to Step 3: Publish your database" title="Direct link to Step 3: Publish your database" translate="no">​</a></h2>
<p>From your SpacetimeDB project, publish a database to the Railway deployment:</p>

<h2 class="anchor anchorTargetStickyNavbar_Y_NL" id="notes">Notes<a href="#notes" class="hash-link" aria-label="Direct link to Notes" title="Direct link to Notes" translate="no">​</a></h2>
\<ul\>
<li class="">The Railway template sets up the SpacetimeDB server itself, but it does not publish your module for you. You still deploy your database schema and logic with <code>spacetime publish</code>.</li>
<li class="">A single Railway-hosted SpacetimeDB instance can host multiple databases.</li>
<li class="">If you want full control over the host, reverse proxy, and operating system setup, see <a class="" href="/docs/how-to/deploy/self-hosting">Self-hosting</a>.</li>
