<p>Before starting, ensure you have:</p>
\<ol\>
<li class=""><strong>Kubernetes cluster</strong> with Gateway API support</li>
<li class=""><strong>Envoy Gateway</strong> installed and configured</li>
</ol>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="step-1-install-gateway-api-inference-extension-crds">Step 1: Install Gateway API Inference Extension CRDs<a href="#step-1-install-gateway-api-inference-extension-crds" class="hash-link" aria-label="Direct link to Step 1: Install Gateway API Inference Extension CRDs" title="Direct link to Step 1: Install Gateway API Inference Extension CRDs" translate="no">​</a></h2>
<p>Install the Gateway API Inference Extension CRDs and controller:</p>
<div class="language-shell codeBlockContainer_Ckt0 theme-code-block" style="--prism-color:#393A34;--prism-background-color:#f6f8fa"><div class="codeBlockContent_QJqH"><pre tabindex="0" class="prism-code language-shell codeBlock_bY9V thin-scrollbar" style="color:#393A34;background-color:#f6f8fa"><code class="codeBlockLines_e6Vv"><div class="token-line" style="color:#393A34"><span class="token plain">kubectl apply -f https://github.com/kubernetes-sigs/gateway-api-inference-extension/releases/download/v1.6.2/manifests.yaml</span><br></div></code></pre></div></div>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id="step-2-configure-envoy-gateway-for-inferencepool">Step 2: Configure Envoy Gateway for InferencePool<a href="#step-2-configure-envoy-gateway-for-inferencepool" class="hash-link" aria-label="Direct link to Step 2: Configure Envoy Gateway for InferencePool" title="Direct link to Step 2: Configure Envoy Gateway for InferencePool" translate="no">​</a></h2>
